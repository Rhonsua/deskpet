# 天依工作人设 Mod 0.1.0

适用于洛天依桌宠 0.7.0 的工作模式，使用现有 Mod API 1。

## 安装与使用

1. 从桌宠打开“扩展功能 / Mod”，点击“打开 Mod 文件夹”。
2. 将 ZIP 中的 `tianyi_work_persona` 文件夹解压到这里，检查 `mod-packages/tianyi_work_persona/mod.json` 存在。
3. 重新打开桌宠，选择“天依工作人设”，勾选“启用此功能”。
4. 点击“选择项目”，选择和工作模式工位一致的目录。
5. 检查内置人设，点击“导入到此项目”。可以编辑预览，或通过“从文件导入”选择自己的 UTF-8 Markdown / TXT 人设。
6. 到该项目的工位新建工作对话后发消息。之后每次在这个项目开启工作对话都会读取项目人设。

建议在当前工作任务结束后导入或更改人设，再新建对话体验。运行中的会话没有即时刷新保证，原有对话历史也可能影响口吻。恢复会话时官方后端会重新核对项目指令，但已有历史会继续存在。

## 工作风格

内置一套洛天依工作人设，温柔、认真、可靠，适当保留音乐、美食和俏皮的角色特征。正常处理写代码、复杂问题和工具任务，诚实说明验证结果。人设通过模型指令影响表达，最终表现与所选模型及当前上下文有关。

## 项目文件与移除

导入在所选项目的 `AGENTS.local.md` 中维护带 `tianyi-work-persona` 标记的一段内容。已有文件须为 UTF-8，可以含 BOM。重复导入会更新这段内容，其他内容按原字节保留。通过“移除此项目的天依人设”移除已导入的段落。移除后若文件为空，会保留空文件。

停用或删除 Mod 后，项目里已导入的人设继续存在。卸载前可对使用过的项目逐一执行“移除”。也可以手动删除文件中开始与结束标记之间的整段。导入位置属于项目文件，可能出现在 Git 未跟踪文件列表中，也可能被同目录下支持该指令文件的其他 Agent 工具读取。

Mod 使用官方 Harness 的项目指令机制 `AGENTS.local.md`。它通过原有 Mod 页面运行，生成项目指令文件。编辑器及最近使用的项目目录来自本地，读取的人设最终随工作请求发给用户配置的模型服务。

本 Mod 不包含美术、声音、模型权重或 API 密钥。导入文件不需要额外安装依赖。Python Mod 与宿主具有相同的进程权限，按桌宠现有方式安装可信的扩展。
