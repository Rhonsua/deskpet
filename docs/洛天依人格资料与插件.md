## 插件位置与加载

- 内置洛天依仅由角色键 `builtin:luotianyi` 绑定，文件为 `pet_chat/personas/luotianyi.json`。显示名称相同的外部角色不会自动绑定天依。
- 外部角色只读取传入角色目录下固定的 `personality.json`，不会导入脚本或执行插件代码。解析后的路径必须仍在角色目录内，包括符号链接的目标。
- 文件最大65536字节，支持UTF-8和UTF-8 BOM；拒绝重复字段、未知字段、不正确的类型、非标准数字、超长内容及不支持的版本。
- 文件缺失时，外部角色安静使用通用陪伴人格；内置文件缺失有提示。损坏、越界、无权限或格式错误会显示简短警告并使用备用人格，不展示文件原文或底层错误。
- 加载器返回不可变数据；这里只提供默认人格，不写数据库，不覆盖用户已保存的人设或记忆。恢复默认需要由界面明确触发。
- 文件在首次打开聊天或切换聊天角色时读取。修改文件后，先切到另一个角色再切回来，或退出桌宠后重新打开；同角色重复开关窗口不会扫描文件。再点击“套用角色默认人设”可更新正文，已有手动记忆保留。

人格JSON提供交流风格与范围提示，本地程序另有任务限制。JSON不执行代码，但其中的文字仍可能影响模型行为；请只使用可信的人格文件。

## 程序层的陪伴范围

本地规则先检查用户输入：明确的积分求解、复杂证明、代码编写等任务直接生成简短的陪伴式回复，不调用模型接口；即使没有配置API也能回应。截图中的 `\int_0^1x exp(x)dx等于多少` 和 `\int_0^5x exp(x^2)dx等于多少` 属于这一范围。拒绝与原问题作为完整一轮保存，保存失败时保留输入。普通简单算数、聊数学的心情，以及“代码一直报错，好烦”这样的倾诉仍可以正常聊天。

如果模型主动输出明显的积分推导或代码，程序会检查流式累积文字及非流式完整回复，终止相应生成并替换为本地陪伴回复，避免已识别的推导继续进入界面或历史。构建后续请求时也会过滤旧历史中的技术解题对；原始本地聊天记录保留，不自动删除。

这些规则独立于可编辑人设、记忆和人格JSON；把人设改成“万能助手”不会关闭本地判定。更新源码后需要退出桌宠并重新打开，**无需重新套用默认人设**；用户已保存的人设和记忆会保留。现有安装包不会因源码更新自动改变。

这一实现使用有限的本地识别规则、输出检查、历史过滤及模型提示，不等同于全面的语义理解或权限隔离。改写、隐喻、未覆盖题型可能漏判，也可能误判；尚未识别的流式前缀可能先显示。不能据此保证所有复杂或绕过式请求都被阻止，也不能保证模型事实准确性。程序继续没有读屏、文件操作或任意代码执行工具。

## JSON Schema（版本1）

以下结构与加载器一致；另有Schema无法直接表达的整份文本累计上限16000字符（去掉各字段首尾空白后累计），以及文件字节上限65536。单字段长度在去除空白前检查，字符上限按Python字符串长度计算。文本须含非空白字符，不允许孤立Unicode代理码位。

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "type": "object",
  "additionalProperties": false,
  "required": ["version", "id", "name", "persona", "scope", "examples"],
  "properties": {
    "version": {"type": "integer", "const": 1},
    "id": {"$ref": "#/$defs/label"},
    "name": {"$ref": "#/$defs/label"},
    "persona": {"type": "string", "minLength": 1, "maxLength": 8000, "pattern": "\\S"},
    "scope": {
      "type": "object", "additionalProperties": false,
      "required": ["allowed", "decline", "guidance"],
      "properties": {
        "allowed": {"$ref": "#/$defs/topics"},
        "decline": {"$ref": "#/$defs/topics"},
        "guidance": {"type": "string", "minLength": 1, "maxLength": 2000, "pattern": "\\S"}
      }
    },
    "examples": {
      "type": "array", "maxItems": 12,
      "items": {
        "type": "object", "additionalProperties": false,
        "required": ["user", "assistant"],
        "properties": {
          "user": {"$ref": "#/$defs/exampleText"},
          "assistant": {"$ref": "#/$defs/exampleText"}
        }
      }
    }
  },
  "$defs": {
    "label": {"type": "string", "minLength": 1, "maxLength": 100, "pattern": "\\S"},
    "topics": {"type": "array", "minItems": 1, "maxItems": 32, "items": {"type": "string", "minLength": 1, "maxLength": 300, "pattern": "\\S"}},
    "exampleText": {"type": "string", "minLength": 1, "maxLength": 1000, "pattern": "\\S"}
  }
}
```

注意：运行时版本号必须是JSON整数 `1`，拒绝 `true` 和 `1.0`，比JSON Schema的整数语义更严格。重复字段即使内容相同也拒绝。
