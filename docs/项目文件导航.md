# 项目文件导航

应用代码统一放在 `deskpet/`。根目录保留启动入口、说明和运行依赖，桌面快捷方式仍调用 `app_entry.py`。

```text
deskpet/                   应用代码
  app.py                   主面板与程序生命周期
  paths.py                 源码／安装版资源根路径
  version.py               版本号
  pet/                     桌宠交互、状态、成长存档、角色接口
  animation/               模型渲染、动作、吸附、移动与特效
  chat/                    陪伴聊天、人格、工作模式和 Harness 适配
    personas/              纯数据人格模板
  music/
    audio/                 输出设备与音频路由
    players/               独立播放器进程与网页脚本
    tools/                 歌单、播放时钟、音乐窗口、首次播放准备
    netease/               登录、歌单、下载、LRC 自动绑定
    lyrics/                歌词解析与字幕设置
    beats/                 节拍分析与缓存
  mods/                    扩展接口、加载器、独立 Mod 源码
  ui/                      样式、背景、图标和通用布局
  runtime/                 自启、后台进程入口、安装版检查
docs/
  guides/                  使用说明
  design/                  设计方案与待办
  release-notes/           更新公告
  history/                 历史开发记录
tests/                     单元与集成检查
packaging/                 后端准备、安装包与 Mod 构建
requirements/              开发、构建、Live2D 依赖入口
assets/                    本地素材；仅说明和配置入库
characters/                本地角色包与公开接口示例
app_entry.py               启动入口
启动桌宠.bat               Windows 源码快捷启动
requirements.txt           运行依赖
README.md                  总使用说明
```

`build/`、`dist/`、`preview/` 是生成物；`local-work/`、`experiments/`、`用户提供的素材/`、`character-packages/` 是本地工作内容，均不提交。`docs/media/` 和模型问题截图只保留本地。私人 Cubism 笔记暂留原路径，避免打断模型制作流程。

## 常用入口

| 任务 | 文件 |
| --- | --- |
| 桌宠交互与状态 | `deskpet/pet/desktop.py`、`deskpet/pet/behavior.py` |
| 模型与移动 | `deskpet/animation/live2d_renderer.py`、`deskpet/animation/walk_runtime.py` |
| 陪伴聊天 | `deskpet/chat/window.py`、`deskpet/chat/companion_runtime.py` |
| 工作侧栏与对话 | `deskpet/chat/workspaces.py`、`deskpet/chat/work_panel.py` |
| 官方工作后端 | `deskpet/chat/work_client.py`、`deskpet/chat/harness_worker.py` |
| 自动安装 Node.js／DSH | `deskpet/chat/harness_bootstrap.py` |
| Mod 接口 | `deskpet/mods/api.py`，兼容旧包的 `pet_mods.api` 导入 |
