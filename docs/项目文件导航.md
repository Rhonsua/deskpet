# 项目文件导航

整理以模块职责和入口索引为主，保留现有可运行文件位置，避免影响安装构建、模型素材路径和并行进行的美术工作。

| 范围 | 主要文件／目录 | 作用 |
| --- | --- | --- |
| 启动 | `启动桌宠.bat`、`app_entry.py`、`main.py` | 源码入口、打包入口、音乐面板和程序生命周期 |
| 桌宠交互 | `desktop_pet.py`、`pet_behavior.py`、`edge_docking.py` | 菜单、持续／临时状态、四边吸附 |
| 模型与动作 | `live2d_renderer.py`、`live2d_motion.py`、`singing_*.py`、`drag_motion.py` | 模型渲染、唱歌和拖动 |
| 鼠标与效果 | `pointer_follow.py`、`mouse_interactions.py`、`pet_effects.py` | 视线跟随、轻抚、动作特效 |
| 外观 | `character_packs.py`、`visual_style.py`、`characters/` | 素材校验、自定义角色加载 |
| 音乐 | `music_library.py`、`audio_*.py`、`remote_audio.py` | 歌单、输出设备、独立音频进程 |
| B站 | `bilibili_*.py/js`、`web_*.py` | 网页播放、控制和循环 |
| 本地功能 | `pet_store.py`、`windows_startup.py` | 成长时长数据库、开机自启 |
| 文字聊天 | `pet_chat/` | 可选 API、人设、历史、手动记忆、聊天窗口 |
| 通用界面 | `compact_ui.py`、`ui_theme.py` | 设置与歌单布局、对比清晰的配色 |
| 检查 | `tests/` | 单元检查、界面／音频／网络集成检查 |
| 发布 | `packaging/`、`requirements*.txt` | 安装包构建、依赖 |
| 文档 | `README.md`、`docs/`、根目录历史设计记录 | 当前使用指南、专项设计、历史进度 |
| 本地私有内容 | `用户提供的素材/`、`local-work/`、`experiments/`、`character-packages/` | 原始素材和实验；保持 Git 忽略 |

聊天说明见 [轻量聊天使用与设计](轻量聊天使用与设计.md)。新增聊天存档位于应用数据目录，和代码、原始素材及成长存档分开。

聊天模块的责任划分、接口约束和双代理协作方式见 [聊天模块顶层设计](聊天模块顶层设计.md)。

洛天依官方与同人设定的来源、纯数据人格插件格式、范围约束见 [洛天依人格资料与插件](洛天依人格资料与插件.md)。默认文件为 `pet_chat/personas/luotianyi.json`，加载与校验位于 `pet_chat/personality.py`。

本地任务限制与输出检查在 `pet_chat/scope.py`；Miku 的独立人格模板位于 `pet_chat/personas/miku.json`，详见 [初音未来人格资料](初音未来人格资料.md)。桌面与托盘共用 `assets/icons/tianyi.ico`，运行时统一入口为 `app_icon.py`。
