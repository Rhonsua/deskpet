# 增加网易云功能：歌词、收藏歌单与节拍同步

记录日期：2026-10-21（北京时间）。计划实施：2026-10-22。

2026-10-22 已实现歌词、歌单适配、独立账号会话和本地节拍模块；实际完成范围与待验收项见文末。下文保留原始方案与调研记录，日期不表示已设置定时执行。

## 要实现的体验

在桌宠音乐面板增加“网易云”入口。用户可以粘贴歌曲或歌单链接，获取歌曲信息与带时间轴的歌词；登录后，尝试读取自己的创建歌单、收藏歌单和“我喜欢的音乐”。歌词可绑定到当前本地 MP3 或 B站视频，在角色附近同步显示。后续把可用的音频节拍接到点脚、身体摆动及音符效果。

界面继续使用白底黑字，不改变已有本地歌单、B站歌单、成长记录和外观选择。

## 歌词字幕

1. 支持粘贴网易云歌曲完整链接并解析歌曲 ID，优先精确绑定；后续再增加按歌名、歌手搜索并让用户确认版本。
2. 获取标题、歌手及可用 LRC，保留来源歌曲 ID；可绑定到一个本地歌曲或一个 B站 BV/分 P。
3. 同名本地 `歌曲.mp3` 与 `歌曲.lrc` 自动匹配；网易云获取失败时仍可手动导入 LRC/SRT。
4. 字幕在角色下方显示一至两行，可开关、调整字体和位置，默认鼠标穿透。歌词按纯文本显示，不执行其中的 HTML、链接或脚本。
5. 使用当前音源的真实播放位置同步；时间落在某句开始时间与下一句开始时间之间时显示该句。暂停、拖进度、切歌、循环和播放源切换都必须同步。
6. 提供提前／延后微调，并按“当前音源与网易云歌曲的绑定”保存。翻唱、Live、MV 片头和剪辑版不自动视为同一个时间轴；一段全局偏移无法修正全部剪辑差异。
7. 缓存成功获取的歌词，记录来源和获取时间；只有用户刷新或缓存失效时再联网。无歌词、纯音乐、网络失败分别显示状态，不挡住播放。

普通 LRC 只保证逐句同步。逐字变色需要逐字或逐词的开始时间、持续时间；不能用每句长度平均分配来冒充真实演唱时间。

## 收藏夹、歌单和登录

这里的“收藏夹”按网易云的内容组织处理：**我创建的歌单、我收藏的歌单、我喜欢的音乐**。收藏专辑、歌手、电台和播客暂不列入第一阶段。

- 未登录：先实现公开歌单链接的读取，列出可见歌曲；不可访问的内容明确提示。
- 登录后：读取本人账号可访问的创建歌单和收藏歌单；尝试提供“我喜欢的音乐”入口。登录不代表一定能读取所有内容，以接口返回和实际权限为准。
- 完整处理歌单分页与曲目分页，展示已读取数量、部分失败和重试；用歌曲 ID 去重，同时保留用户歌单顺序。
- 喜欢列表接口的实现标为“无序”，不能直接把返回 ID 列表当作客户端中的排序；优先核对对应歌单的顺序，无法还原时说明排序依据。
- 导入是本地只读快照，附来源 ID 和更新时间；刷新时更新云端快照。用户本地添加的曲目和排序另存，不被刷新覆盖，也不向网易云自动写回收藏、删除或排序操作。
- 私密内容仅尝试读取当前登录账号本来可见的部分；失效时提示重新登录，不循环重试。
- 使用桌宠自己的登录会话，不读取现有浏览器或网易云客户端的 Cookie，不要求用户在聊天里粘贴密码或 Cookie。
- 登录凭据使用 Windows 用户凭据保护方式保存；不写入源码、日志、截图、可转发角色包或安装包。提供退出登录并清除凭据、个人歌单缓存的入口。

用户操作目标：**打开网易云页 → 扫码登录 → 选择创建／收藏／喜欢 → 勾选歌单导入 → 绑定可用音源并显示歌词**。

## 网易云歌曲如何播放

读取歌曲标题、歌词和收藏列表，与取得可播放的音源是两个独立功能。

第一阶段允许把网易云条目绑定到已有本地 MP3 或 B站曲目；未绑定时可打开网易云原页面。仅打开外部网页时，没有验证到真实播放进度就不启动同步字幕、自动切歌或累计听歌奖励。

网易云网页播放作为单独的接入项验证，优先沿用已有 WebView2 辅助进程的组织方式，并单独维护网易云地址和事件适配，保持 B站入口现有的地址限制。需要确认：登录、实际可播放时长、播放进度、暂停、跳转、结束事件、单曲循环、列表切换以及后台运行。

能读取歌单不意味着每首歌都能完整播放。付费、下架、地区限制和网页端限制按网站实际返回处理；只提供试听时明确标识。验证通过后才能把网易云视为正式播放源。

## BPM 与动作跟拍

- 本地音频先读取已有 BPM 标签；没有或用户要求重新分析时，在后台分析音频，保存估计 BPM 和逐拍时间。
- 分析结果按文件内容／修改信息建立缓存，不阻塞桌宠启动和首次播放；进度可见、可取消，失败继续使用现有固定节奏。
- 提供手动 BPM、起拍偏移以及半速／倍速校正；固定 BPM 与实际逐拍结果分别保存。
- 逐拍时间驱动点脚、重心和背景音符，避免只改变整段动画快慢。拖起、落地、休息和鼠标互动仍遵守现有持续状态与临时动作规则。
- 本地播放暂停、跳转、循环、倍速变化时，字幕与节拍都以播放时间为准，不另起一个不断累积的独立计时器。
- 不假定网易云歌单或歌词接口提供可靠 BPM。没有可分析音频时允许手动输入；B站和网易云的自动节拍分析留待各自音频数据链路验证后再接。

## 接入位置与数据边界

拟增加网易云适配层、歌词解析／绑定层和后台音频分析层，由音乐面板统一发布“播放源、曲目 ID、位置、播放状态、倍速”给字幕及动作控制。可复用 `audio/remote.py` 与 `bilibili_player.py` 的现有状态，不把网络请求或分析工作放进动画每帧刷新中。

个人收藏、歌词缓存、绑定、节拍结果和登录凭据放在应用数据目录；源码仓库只保存代码、公开技术说明和人工测试夹具。测试不用真实账号快照或整首歌词入库。延续现有规则：角色素材、模型、安装包、个人数据和凭据不上传 GitHub。

## 2026-10-22 的实施顺序

1. **优先完成歌曲链接与歌词**：网易云链接解析、后台获取、LRC 解析与缓存、本地／B站绑定、逐句字幕及时间微调。
2. **再做公开歌单导入**：曲目 ID、名称、歌手、分页、去重、部分失败和精确绑定，保证导入数据不破坏原歌单。
3. **再接账号收藏**：主动扫码登录、退出、过期处理、创建／收藏歌单和喜欢列表；用用户授权登录后的实际结果验收，不保存账号内容到仓库。
4. **完成本地 BPM 和跟拍**：后台分析与缓存、手动校正、字幕／动作统一使用播放时钟。
5. **单独验证网易云网页播放**：通过真实进度、切歌和后台循环检查后再宣布支持；当天未完成的部分标注未完成，保留已完成的歌词和导入能力。

## 验收重点

- 获取成功、无歌词、无逐字歌词、纯音乐、断网、超时和接口变化均有明确结果，界面不冻结。
- 歌词暂停、切歌、拖进度、循环、时间偏移和两个音源之间切换，不残留上一首字幕。
- 同曲不同版本必须人工确认，缓存可刷新；歌词内容按纯文本处理。
- 歌单完整分页、喜欢列表顺序、缺失曲目、重复导入和刷新失败可恢复。
- 扫码取消、二维码过期、会话过期及退出清理；日志、Git 暂存区和安装包中无凭据或真实个人收藏。
- 本地节拍分析可取消、不阻塞播放；唱歌被拖动或休息打断后仍按现有状态规则恢复。
- 模型大小、四边停靠、鼠标穿透、本地音频及 B站循环不因新增功能回退。

### 易用性反馈及落实

用户反馈：手动配置API、绑定外部音源、手动填写BPM的门槛过高，希望主要通过网易云听歌；节拍只保留开关，首次自动解析、之后复用。

- 默认直连扫码，自动读取歌单，账号及私人缓存隔离；不需要电脑网易云客户端和自建服务。
- 打开歌单后直接播放，自动绑定同ID歌词。页面内提供暂停、上下首、四种队列模式；实际音频位置驱动字幕和听歌计时，获取信息或下载不计奖励。
- 试听明确标记；使用账号正常音源，不调用解锁或替代平台。下载单独查询下载接口并校验文件，音频和LRC同名保存，权限不足不冒充下载成功。
- 节拍默认关闭；打开后首播自动准备，已缓存直接播放，等待可跳过。在线只临时读取正常音源做分析，完成后清理临时音频，保留分析结果。切歌、取消、退出及暂停意图优先于迟到响应。
- 真实账号及会员下载仍待本人操作验收；并非所有歌曲都有完整音源或逐句歌词。
