# 被动上下瞬移

实现日期：2026-10-27。当前已接入源码，尚未更新安装包。

## 表现

1. 原地出现圆形、蓬松的淡蓝白色烟雾和彩色礼花，烟雾盖住人物。整体为圆形云团，边缘由小圆云团组成，不采用竖长条状遮罩。
2. 人物隐藏，烟雾消散，保留一个短暂的全透明空档。
3. 在空档中一次性改变窗口纵坐标，横坐标保持不变。
4. 新位置先出现烟雾礼花，然后人物逐渐浮现、烟雾消散。

全程约 2.05 秒；不播放音效，不更改音符、等级、音乐进度或保存的活动。人物使用正常待机渲染，效果位于人物前方，兼容静态 PNG 与 Live2D，无需为角色包增加素材。

## 调度与边界

- 仅被动触发；设置提供默认开启的独立开关，无菜单手动触发入口。
- 初次随机检查间隔 45–120 秒；成功触发后冷却 600–780 秒，并保存截止时间。
- 空闲或陪听状态、没有音乐播放、最近 15 秒无交互、无其他临时动作或工具窗口时才允许触发。
- 不和散步并行，不在拖拽、摸摸、吸附、睡觉、手机状态下触发。
- 在当前显示器可用工作区域内，先随机选择有空间的上方/下方，再随机取距离。最短为角色窗口高度的 40%（至少 48 逻辑像素），最长为两倍高度，受实际空间限制；没有足够空间则跳过，不消耗冷却。
- 显示器或工作区域变化时中断并将角色移回可用区域，不跨屏瞬移。

## 中断与绘制

- 使用 `teleport` 临时动作层，正常完成后恢复原保存状态。
- 用户点击/拖拽、打开工具、切换角色/大小/活动、隐藏桌宠、关闭开关或开始播放音乐，会终止动作；已移动则留在新位置，否则留在原位置。
- 瞬移不调用窗口隐藏或窗口透明度 API，只控制绘制透明度。取消时自动恢复正常绘制，不留下隐藏的桌宠。
- 全透明期间清空命中区域；烟雾层鼠标穿透。人物可见时可以直接点按打断；全透明的短暂阶段仍可通过托盘打开面板或停止自动动作。
- 使用比角色画布更宽的独立方形前景效果窗口，让圆形烟雾自然覆盖完整人物；不改变人物窗口的横坐标、大小或角色包锚点。
- 烟雾图层缓存并整体淡出，避免半透明云团叠加产生交叠虚影。背景动效在瞬移期间暂时隐藏，防止人物消失后仍有待机星光残留。
- 用有限的时间步推进，系统卡顿/恢复后不会跳过整段遮挡效果。

## 文件与验证

- `teleport_controller.py`：随机目标、冷却、阶段时序。
- `teleport_runtime.py`：桌面窗口、状态、设置和中断整合。
- `teleport_effects.py`：缓存的前景烟雾、程序绘制礼花。
- `tests/test_teleport.py`：随机方向、屏幕边界、透明空档、冷却持久化、临时状态。
- `tests/smoke_teleport.py`：隔离 Qt 实测，`--live2d` 加测本地原生模型；使用 Windows 图形环境运行后者。
- `preview/teleport/`：实际桌宠绘制截图，仅用于本地验收，不随角色素材或发行包提交。

已验证：Windows 原生 Qt + 本地 Live2D 的人物透明时序、独立圆形烟雾层、消失后移动及恢复；静态 Qt 调度和操作打断；原有散步回归通过。没有改动用户的实际设置或正在使用的安装版。
