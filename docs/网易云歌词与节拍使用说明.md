# 网易云、歌词字幕与节拍跟随

2026-10-22 源码功能更新。现有 0.4.1 安装包和免安装 ZIP 没有重新打包，不包含本次更新。

## 入口与操作

启动源码版，在音乐面板点击“网易云 / 歌词字幕 / 节拍跟随”，也可使用系统托盘的音乐工具入口。工具窗口延迟创建；启动桌宠不会自动登录、请求歌单或分析歌曲。

公开歌曲和歌单读取无需安装网易云桌面客户端。这一版不控制网易云客户端，也不能监听它的播放进度。

1. 打开“网易云 → 我的歌单”，用手机网易云 App 扫码确认；登录后自动显示歌单。
2. 双击一个歌单，点击“播放歌单”，或双击歌曲直接播放。公开歌曲／歌单也可在“歌曲与歌单”粘贴完整链接读取。
3. 网易云歌曲自动获取并同步歌词，**不需要手动绑定本地文件或 B站视频**。
4. 页面底部可以暂停、上下首及切换顺序／列表循环／单曲循环／随机播放，主音乐面板也可控制进度和音量。
5. 想让动作跟拍时，打开“节拍跟随”的唯一主开关；首次播放前自动解析，以后复用结果。

使用正常播放接口取得当前账号可用的音源，试听会显示“试听片段”；不可播放曲目会跳过，多个失败后停止自动尝试。暂停、切歌、账号退出和本地／B站切换会撤销旧播放请求，后台收到旧结果也不会重新开声。

歌单快照与本地歌单分别保存，刷新不覆盖本地曲目和排序。分页缺失、不可访问及读取不完整会提示，失败刷新不以残缺结果覆盖上次完整快照。

## 下载音频与 LRC

**整单下载（源码新增，现有 0.4.2 安装包尚未包含）：** 在“我的歌单”选中歌单，点击“下载选中歌单到本地…”，选择文件夹即可。也可以打开歌单后点击“一键下载整个歌单＋LRC…”。会重新读取歌单及分页，按云端顺序处理，不受多选下载 100 首的限制（歌单读取上限 20000 首）。若接口只返回部分曲目，会明确显示不完整；无法下载的歌曲单独报告，并继续处理其余曲目。

成功下载的音频和 LRC 使用相同文件名，自动按音频的完整本地路径绑定歌词。下载的 MP3 会逐首加入新建的“歌单名（下载）”本地歌单，不切换当前歌单、不打断正在播放的歌曲；取消后已保存的文件、绑定和本地歌单条目保留。已有音频或同名 LRC 时，使用新名称保存整对文件，不覆盖旧文件。没有歌词或绑定失败时会分别说明。音频保留接口返回的真实格式，其他格式仍保存并绑定，当前 MP3 本地歌单不接收其他格式。

在歌曲列表选中一首或按 Ctrl／Shift 多选，点击“下载歌曲＋LRC”，选择保存文件夹即可。只需要歌词时点击“只保存 LRC”。下载使用正常下载接口，**能够播放不代表账号具有下载权限**；不可下载或仅返回试听时会报告未保存，不改用播放地址导出。

有歌词时保存同名 UTF-8 `.lrc`，无逐句歌词时只保存音频并说明。保留真实音频格式，不强行改成 MP3；遇到同名文件会询问“覆盖”或“跳过”，可勾选对本次下载中的所有重名文件采用相同选择。歌曲和本次取得的歌词一起处理，跳过保留原文件；只保存 LRC 时同样询问。音频完整下载并校验后才会询问并替换原文件。可以取消，临时文件会清理，已完成文件保留。多选下载每批最多 100 首，超过 20 首需要确认；整单下载按前述独立入口处理。完成后显示逐首结果及跳过数量，单文件限制 200 MiB。

## 一个开关的节拍跟随

“跟随歌曲节拍”默认关闭。打开后，本地歌曲和网易云完整音源首次播放前自动准备节拍；已有 BPM 标签、手动校正或有效分析缓存时直接使用。解析结果保存在本机，下次同一版本的歌曲无需重复解析。本地文件变化、网易云音频版本信息变化时重新准备。

准备期间有“跳过分析，直接播放”按钮；失败或超时也继续播放，使用原有演示动作。关闭开关立即停止准备并继续当前播放意图。等待时暂停、切歌或退出账号不会被旧分析结果重新启动。

网易云分析只临时读取正常可播放音源，完成或取消后删除临时音频，仅保留节拍结果；这不生成可导出的离线歌曲。试听片段不做自动分析，B站目前仍只支持高级手动校正。若软件或电脑异常退出，临时目录可能残留待清理文件。

## 字幕与高级校正

直接右键桌面上的歌词可打开菜单：选择白色、天蓝、青绿、粉色、金黄或自定义颜色，切换“左键穿透”，以及隐藏歌词。左键穿透默认开启，右键仍可打开设置；隐藏后到“音乐 → 歌词字幕”勾选“显示角色附近的歌词字幕”恢复。颜色、显示状态和穿透设置自动保存，重启后保留；黑色描边继续保留，便于浅色桌面阅读。歌词字幕页也提供颜色和穿透设置。

若旧版歌词像空心字、颜色很暗，是黑色描边盖住了中文细笔画。新版改为先描边再填实文字，同一颜色即可恢复清晰，无需重置颜色设置。

- `歌曲.mp3` 同目录的 `歌曲.lrc` 自动匹配，也可导入 LRC/SRT。支持逐句字幕，无时间轴的文本仅预览，未实现逐字卡拉 OK。
- 歌词固定跟随桌宠的相对位置，不单独吸附或限制在屏幕内；靠近边缘时允许超出屏幕并自然裁切。字号、上下位置和水平微调仍可在“歌词字幕”页调整。
- 歌词微调按毫秒计，**正值提前显示，负值延后显示**；按音源与歌词绑定分别保存。Live、翻唱和剪辑版不自动视为同一时间轴。B站绑定区分视频及分 P。
- 字幕取实际播放位置，支持暂停、跳转、循环及切歌。播放器失联或网页跳转时隐藏，恢复有效位置后继续同步。
- 节拍在独立后台进程估计 BPM 和逐拍时间，不修改原音频。自由速度、弱节奏或变速曲目可能不准确。
- 已修复部分 48 kHz 双声道 MP3 分析立即失败的问题：按音频原始格式解码，避免强制转换采样率时产生空缓冲；同时保留首条失败原因。5 首现有歌曲只读复测均完成分析，用时约 3～5 秒。重启新版后，原来失败且没有缓存的歌曲会在下次播放时自动重试。
- 手动 BPM、起拍偏移、半速／倍速和重新分析收在默认折叠的“高级校正”。BPM 为 0 时恢复标签或分析结果。**起拍偏移正值延后第一拍，负值提前第一拍**，与歌词的提前量含义不同。
- 有效节拍驱动唱歌的左右脚、重心和背景音符，保留持麦及转身；拖动、落地、睡觉和互动仍遵守原状态优先级。无有效节拍时使用原演示动作。
- B站目前仅支持手动 BPM，未做音频自动分析。半速／倍速校正只影响动作节拍，不改变歌曲播放速度。

## 登录查看我的歌单

现在推荐通过独立的 WebView2 窗口打开网易云官方页面完成登录，无需填写 API 地址、部署服务或安装电脑网易云客户端。浏览器组件与 B站播放使用同一技术，但登录窗口使用独立临时会话，不读取 Edge 或 B站的登录数据。

1. 退出旧桌宠，通过项目的“启动桌宠.bat”启动新版源码。
2. 打开音乐面板 → “网易云”，默认进入“我的歌单”。
3. 点击“官方网页登录（推荐）”，在弹出的网易云网页右上角点击登录，按网页提示扫码或完成验证。成功后窗口自动关闭，桌宠自动接收登录状态。不要在登录完成前关闭桌宠音乐窗口，否则会取消本次登录。
4. 登录后自动显示创建和收藏的歌单。双击歌单查看歌曲；点击“我喜欢的音乐”查看喜欢列表。
5. “记住登录”默认勾选，在本机加密保存；下次打开网易云页自动验证并加载歌单。失效时重新登录。可以取消勾选，仅本次使用，或点击“退出登录”清除。

“直接扫码（备用）”已更新二维码申请、状态检查和账号核验请求。若官方窗口在手机确认后仍停留在二维码，可关闭它，再用这个入口生成新二维码重试；不要继续扫描旧二维码。8821 会明确提示需要验证，不会当成账号被封或直接清除已有登录。

网页登录期间，桌宠会区分“等待扫码”“已扫码，等待手机确认”“已确认，等待登录会话”和账号核验状态。只有核验成功才视为登录完成。网页已经登录但桌宠没有接回时，可点“我已在网页完成登录，重新检测”；网页仍只有二维码时，这个按钮不能代替官网完成登录。

若停在“检测到凭据，但官网尚未返回可验证的账号”，桌宠会自动启用独立账号核验：使用当前登录窗口自己的凭据直接查询账号，不依赖网页内脚本执行结果。查询在后台进行，每次最多等待 8 秒、正常重试间隔至少 15 秒；点“重新检测”可提前重试。页面会显示会话未生效、请求被拒绝、网络失败或响应异常。只有当前凭据取得有效账号才接回，凭据变化后丢弃旧查询结果；不会仅凭 Cookie 存在就显示登录成功。此路径已通过合成账号测试和匿名联网检查，真实账号能否完成仍需重试确认。

不自动修改云端收藏或排序。喜欢列表优先用对应歌单原顺序，无法取得时说明 ID 列表无序。

“高级连接设置”默认收起，仅供需要自定义兼容社区服务的用户使用。以前填过服务地址的用户，可清空并保存恢复默认连接；切换前会退出旧会话。桌宠不使用第三方公共登录代理，二维码在本机生成。

会话可仅本次使用，或用 Windows DPAPI 加密保存。网页登录只读取桌宠新建的独立窗口会话，不读取 Edge、B站或网易云客户端的既有 Cookie，无需在聊天里提供密码或 Cookie。退出、重新登录或切换服务会先清除旧会话及私人缓存；确认失效后提示重登，不循环重试。

## 验证状态与回来后的测试

实机反馈：直接扫码流程曾返回 **8821**；官方窗口也出现手机确认后仍显示二维码的情况。截图和当前反馈不足以确定官网未完成登录的具体原因。这次修正登录请求协议、补充扫码阶段观测和账号核验，并修复 Windows 网络组件与加密组件加载顺序导致的崩溃。新版备用扫码已实际联网取得二维码并返回 801（等待扫码）；浏览器完整回传、自动关闭、取消与账号切换用合成账号验证通过。**真实手机扫码和确认尚未验证解决**，仍需本人重试。

公开歌曲信息、歌词、歌单及匿名二维码申请／等待扫码已实测。账号流程、自动加载歌单、分页、取消、失效与退出已用合成数据测试；**本人手机确认、私人歌单权限与完整性仍待真实账号验收**。网易云站内接口可能变化，不能保证所有内容都可访问。

已实现网易云正常音源直连播放，无需打开内嵌网页。一个未登录可用的公开歌曲已通过真实 HTTPS 原生静音实播，进度超过2秒，无错误，随后立即停止且未保存音频文件。歌单控制、暂停／跳转／结束事件和节拍缓存另用合成音频验证；真实账号的私人歌单、会员下载及地区权限仍待本人验证，不保证所有曲目可播放或下载。

回来后直接在“我的歌单”扫码并播放，确认歌词、暂停、拖进度、切歌和拖动桌宠后能恢复。节拍开关打开后，首播会准备，再播应直接复用；下载结果可在所选文件夹检查音频和同名 LRC。

## 数据与依赖

数据位于桌宠应用数据目录的 `music-companion/`：`lyrics/lyrics.db` 保存歌词与绑定，`beats/` 保存分析和校正，`netease/` 保存配置、缓存及加密会话，`source-bindings.json` 保存条目到实际音源的映射。个人内容不写入代码或安装包。

入口为 `music_tools/companion.py`、`music_tools/clock.py`；模块为 `netease_music/`、`music_lyrics/`、`music_beats/`。依赖由 `requirements.txt` 和启动脚本检查；音频解码使用 Qt 自带后端，不要求另装系统 FFmpeg。
