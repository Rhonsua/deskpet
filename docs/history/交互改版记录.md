# 角色交互改版

日期：2026-10-17

用户要求参考 Steam 上萝莉丝桌宠的界面，强调直接互动和动态表现。此前常驻音乐卡片面板的方向已取消。

## 参考依据

- [Steam《虚拟桌宠模拟器》](https://store.steampowered.com/app/1920960/VPetSimulator/?l=schinese)：官方对摸头、提起、舞动等互动动画的说明。
- [VPet 官方项目](https://github.com/LorisYounger/VPet)：角色显示、工具栏、消息气泡与动画组织。
- [ToolBar.xaml](https://github.com/LorisYounger/VPet/blob/main/VPet-Simulator.Core/Display/ToolBar.xaml)：贴身操作入口、状态条与展开面板的组织。

本项目用 PySide6 独立实现交互和布局，继续使用洛天依经典 V3 公式服。

## 本轮实现

1. 平时只显示角色，透明区域按照角色轮廓处理点击。
2. 点头部摸摸、点身体戳一戳；按住或拖动提起，松开后落地回弹。
3. 右键/双击展开贴身菜单，显示等级、音符、经验、饱食和心情，提供摸摸、投喂、音乐、休息与设置。
4. 本地对话显示为短暂气泡，互动配有爱心、音符和睡眠符号。
5. 新增眨眼、挥手回应、抱包子、惊讶提起四组状态图，结合呼吸、摇摆、咀嚼节奏和回弹变换。
6. 点击唤醒休息状态，播放音乐时摇摆。
7. 歌单、成长与更多设置使用按需打开的小工具窗。
8. 自启默认关闭，由用户在菜单设置开启；登录后只显示桌宠。

当前尚未实现逐帧行走、爬墙、连续舞蹈与骨骼动画。动作预览来自实际 Qt 渲染器。

## 播放和自启验证

- 已完成多歌单、迁移、搜索、移除排序、循环随机播放及上次曲目/进度恢复。
- 修复本机默认音频后端的重采样异常，Windows 改用原生后端。
- 修复 Windows 路径分隔符差异导致的曲目恢复失败。

- 自启启停在独立测试注册表位置验证，没有替用户开启实际自启。
- 早期播放测试误写的三条临时歌曲条目已清理，恢复默认音量 60% 与顺序播放；现在的测试显式使用独立临时设置文件。

预览：`docs/interaction-demo.gif`。素材及实际提示词见 `assets/character/states/制作记录.md`。

## 残影、配色与边缘探头修正

- 每次重绘以 Source 合成模式清空透明画布，再绘制当前姿态；取消逐帧修改原生窗口裁剪，避免 Windows 分层窗口旧像素残留。命中区域仍随当前角色计算，Windows 透明窗口使用绘制后的 alpha 处理透明区域。
- 播放模式、歌单、外观三个下拉框使用独立列表视图并明确设置文字、背景、选中背景及选中文字；菜单和输入框也补充相同配色，避免跟随系统深色选项而冲突。
- 拖拽松手后，当前屏幕可用区域内约 32 逻辑像素的边缘会吸附；约 0.9 秒后收成探头。左右转头、顶部倒挂、底部露头；悬停展开，移开后收回，按住拖回桌面解除停靠。
- 停靠在窗口内部变换和裁切，不把整个窗口移出桌面；保留可点击的头部，兼容可用区域负坐标，缩放及重启会保留边缘。
- 新增 `characters/README.md` 预留角色包目录，外部角色加载留待后续。

验证：23 项逻辑测试通过；独立临时设置下的原有交互检查，以及四边停靠、收放、缩放、恢复、拖离、同一画布连续切换状态无旧像素、深色配色下拉框检查通过。新增检查在离屏与本机 Windows 窗口后端均通过；已人工查看四边探头和下拉列表截图。此验证尚不等同于真实多屏、桌面点击穿透和长期显示验证。

## 侧躺休息、手机与蓝牙音频

- 精致版休息改为横向侧躺、头靠枕头、盖蓝白被子；补充程序呼吸与睡眠符号。
- 根据本地用户参考姿势，使用 imagegen 生成同一角色的被窝手机状态，加入微光和轻点反馈。入口在“休息”子菜单，支持点击收手机、切换睡觉或起床。
- 休息状态保持完整展开，避免被边缘探头裁切；拖拽会起身。播放状态不再强制解除睡眠。
- 设置新增“音频输出”，支持跟随默认输出或直接指定已连接设备，自动刷新列表、显示当前路由，保存指定设备；断开时回退默认，重新出现时恢复指定项。
- 实测本机 Qt 能枚举 EDIFIER K710W；修复旧实现未监听默认设备变化的问题。
- 真实静音 MP3 切换测试额外发现 Windows 后端暂停切换设备后进度归零：现在切换前捕获曲目、进度及播放状态，重新建立输出后恢复同一曲目，等待媒体可跳转再恢复进度；暂停时保持不播放。切换可能产生短暂停顿。
- 设置页增加滚动容器，避免新增设备选择后底部说明被挤出。

验证：29 项逻辑测试通过；交互、Windows 后端停靠与深色下拉框检查通过；静音 MP3 实际输出切换、暂停进度、恢复和单曲循环通过。已查看实际大小睡眠/手机姿态与设置截图。蓝牙耳机实际听音与物理断开重连仍需使用确认。原始用户素材留在本地，不上传仓库；生成图及提示词记录随项目保存。

## 边缘改为按住拖出，加入鼠标穿透

- 覆盖之前的悬停展开规则：鼠标经过、单击、原地按住探头均不展开，按住移动超过拖动阈值才提起并离开边缘。鼠标停留不会阻止自动收回；菜单、睡觉和玩手机等明确展开行为保留。
- 设置和系统托盘新增“鼠标穿透”，默认关闭并保存设置；开启后角色仍显示和活动，点击交给下方窗口。歌单与设置窗口继续接收输入。
- 托盘提供“关闭鼠标穿透并找回天依”，无需先点击角色即可恢复操作。输入模式切换不改变持续活动状态。

验证：新增检查在离屏与 Windows 原生窗口后端均通过，覆盖四边悬停/单击/按住不展开、拖出、穿透开关同步、重启恢复、托盘解除，以及 Windows 原生输入透明样式的设置与清除；既有界面和边缘回归检查通过。尚未确认不同桌面软件下的实际点击透传与长时间使用。
