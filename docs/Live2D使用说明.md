# Live2D 与角色切换

0.3.0 默认使用 Live2D 洛天依。更多设置中的“角色外观”可选择动态模型、两种静态洛天依或放入文件夹的 PNG 角色包；选择会保存，音乐、等级和听歌记录共用。

## 本地素材与源码

GitHub 提供代码和文档，新增 Live2D 素材、Cubism 工程、自定义角色包和安装文件仅保留本地。模型放在 `assets/live2d/tianyi/`，入口为 `action-map.json` 的 `model` 字段，入口再引用同目录内的纹理、MOC3、动作等文件。没有模型的源码副本可使用内置静态角色；不会自动下载模型。

安装源码依赖使用 `requirements.txt`。原生渲染要求系统支持 OpenGL；初始化或运行渲染失败时回退到静态精致版。安装包内包含运行依赖，用户无需另装 Python。

## 动作和互动

- 持续活动包括待机、听歌、唱歌、睡觉及玩手机；提起、落地、摸头、挥手和进食是临时动作，结束后恢复之前的活动及动作进度。
- 拖起有弹性拉伸和横向惯性；支持新参数的本地模型会紧闭双眼、小口惊呼，双臂上下扑腾。松手后收手、落地回弹，并恢复原活动；从睡觉提起后仍回到睡觉。旧模型保持原提起动作。
- 唱歌以固定节奏完成左右转向和四段轮换步法，不识别实际音乐 BPM，也不是音频驱动口型。
- 附近鼠标可以驱动视线和轻微转头，无需按住。拖动、休息和停靠时暂停跟随。
- 手边短暂停留可触发挥手回应；有冷却，不自动发成长奖励。普通点击角色只打招呼，不进入摸摸。
- 只能从控制面板点击“摸摸”进入摸头模式，气泡只表达开心，不提示手套或操作说明。将鼠标移到头部并轻轻左右移动即可抚摸，无需按住；按住左键也不会拖起角色。右键角色或桌宠应用内按 Esc 退出，也可重新打开互动菜单退出。
- 接触时会显示覆盖在头顶的白色手掌，随抚摸方向轻压、倾斜；此时隐藏重复光标，移开后手掌抬起消失。摸摸模式的水平判定以头部中心为基准扩大为原来的两倍，高度与人物显示大小不变；退出摸摸后恢复普通人物命中范围，不增加额外输入窗口。
- 轻触先柔和眯眼，持续轻抚会闭眼并轻晃头、摆动发尾。新 Cubism 模型的专用参数负责头顶局部轻压。移开后平滑释放，原来的活动和动作进度继续，音乐播放不受影响。站着不动不会重复奖励。
- 视觉反馈独立于成长奖励冷却，持续摸头不会被奖励间隔打断。实际有效抚摸才按原规则增加心情（每分钟最多一次，每日最多十次）；被动免按键互动不发成长奖励。切换角色、休息、隐藏桌宠或开启鼠标穿透会退出手套模式。其他窗口遮住角色时停止响应。
- 音符、爱心、闪光、睡眠 Z 字等背景效果避开人物轮廓，显示层始终鼠标穿透。跟随、免按键互动和背景效果都可单独关闭。
- 睡觉和手机按头部大小校准显示比例，避免直接按整张画布缩成很小一团。

模型使用二维变形和互斥姿势，尚无完整侧背面转身、独立手指或完整肘腕骨架。静态角色包使用自身姿势图结合程序动画，不套用洛天依专属腿部切片。

## 自定义角色

在“更多设置 → 角色外观 → 打开角色文件夹”中添加角色，点击刷新后选择。源码目录是项目 `characters/`；安装版是 `%LOCALAPPDATA%\TianyiPet\characters`，更新和卸载程序不会清空这个角色目录。详细画布、动作命名、锚点和校验规则见 [角色素材规范](../characters/README.md)。当前外部接口仅支持 PNG，尚不支持外部 Live2D。

## 本地安装包

构建规则只包含当前洛天依导出及静态素材，不扫描用户角色包。安装测试使用临时数据，验证实际 Live2D 帧、动态/静态切换、音频与 WebView2 辅助程序，并检查卸载保留额外用户文件。构建方式见 [安装包说明](../packaging/README.md)。
