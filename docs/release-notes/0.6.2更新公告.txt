洛天依桌宠 0.6.2

本次更新
1. 新增 GitHub 发行版更新检测：启动后在后台检查新版本，也可在“打开歌单 → 设置 → 版本与更新”手动检查。
2. 发现新版时显示版本、安装包大小和更新公告，可选择下载更新、稍后再说或跳过此版本；后台检查可以关闭。
3. 更新包后台下载，支持取消，下载完成核对大小与 SHA-256。确认退出后打开安装程序，不会强制中断正在使用的桌宠。
4. 安装器默认沿用原来的安装位置，更新保留个人设置、歌单、聊天记录、背景和已准备的工作后端。

延续 0.6.1
- 工作模式采用项目与对话侧栏、上方消息和底部输入框；进入工位默认显示最后一条消息。
- 复用同一项目未使用的空对话，退出后不保留空占位；保留草稿和已有工作记录。
- 聊天、工位、歌单和网易云等页面可以独立调整背景位置与缩放，保留原有半透明外观。

安装与使用
- Windows 10 / 11 x64。先从系统托盘退出旧桌宠，再运行 TianyiPet-0.6.2-Setup.exe，覆盖安装到原位置。
- 0.6.1 及更早的安装包没有更新检测，需要先手动安装本版；之后可在桌宠内选择更新。
- 首次使用工作模式会自动下载并校验 Node.js，再安装匹配的官方 DeepSeek Harness 后端；已准备好的环境直接复用。使用者自行配置模型 API。
- 安装包仅带当前洛天依素材和通用角色、人格及 Mod 接口，不包含 Miku、Mod 本体、个人背景、音乐、聊天记录或 API Key。
- 网易云与 B站网页登录需要 Microsoft Edge WebView2 Runtime。
- 本包为未签名发行包。更新检测需要能够连接 GitHub；网络异常时可以继续使用当前版本。
