洛天依桌宠 0.7.0

本次更新
1. 陪伴模式支持本机语音。启用朗读后，天依会在语音准备好时一起显示文字和播放声音，主动搭话也可朗读。可随时停读，语音输出跟随音乐的设备设置。
2. 在「和我聊天 → 陪伴模式 → 语音设置」打开语音包文件夹，放入兼容的 ZIP 即可选择声音。模型在后台加载。语音包、参考录音及 GPT-SoVITS 环境需自行准备，文字聊天可以单独使用。
3. 天依会记住明确告诉她的称呼和偏好，根据话题想起相关对话。可以在「人设与记忆」查看、删除或关闭自动记忆。
4. 可以把选歌交给天依。说「随便唱首歌听听」就从已有歌单挑一首，也可以指定心情，让她从本地和 B站歌单选歌。
5. 每天累计听歌的前 60 分钟，每满 5 分钟得 6 个音符，一小时共 72 个。之后每满 5 分钟得 2 个，每天最多 100 个。暂停或重启后接着累计，当天已领取的音符和已有余额保留。
6. 自定义静态角色包可以提供工作和等待审批的姿势，也可为躺姿、坐姿单独设置摸头位置。

安装与更新
在 Windows 10 或 11（64 位）上，从系统托盘退出旧桌宠，运行 TianyiPet-0.7.0-Setup.exe，安装到原位置即可。0.6.2 及以上版本也可在「打开歌单 → 设置 → 版本与更新」下载并校验安装包。原有歌单、成长记录和聊天可继续使用。
