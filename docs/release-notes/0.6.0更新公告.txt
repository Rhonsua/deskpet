洛天依桌宠 0.6.0 测试版

1. 新增陪伴与工作双模式。首次工作会先自动下载官方 Node.js 免安装版，再安装匹配的官方 DeepSeek Harness 后端，显示准备进度、支持停止，完成后继续本次任务。用户无需手动安装 Python、Node.js 或 Harness；填写自己的 API 配置后即可使用文件读取、编辑、命令执行、审批与项目会话恢复。
2. 后端与 Node.js 独立保存在用户数据目录，已准备好时不重复下载，不修改系统环境变量，也不依赖官方 DSH 桌面端的安装位置。工作会话、配置和记忆与运行文件分别保存，更新重装程序不覆盖个人记录。
3. 陪伴模式可按对话执行动作、播放本地与 B站歌单，空闲主动聊天由所配置的 AI 生成。
4. 聊天与歌单支持整窗自定义背景、自动居中裁切及半透明控件。主控制面板的“打开歌单”位于“和我聊天”下方。
5. 新增 Live2D 工作与蛄蛹动作。每次向左散步有 25% 概率改为蛄蛹，涵盖手动、随机与陪伴指令。拖尾随实际位移生成，第 3 轮结束后第 1 轮开始用 5 秒淡出；蛄蛹不单列手动入口。
6. 优化音频输出跟随、动作与页面加载，修复横向姿势缩放漂移等问题。

测试说明
- 仅包含洛天依当前素材、通用角色接口与 Mod 接口，不包含 Miku、其他用户角色包、Mod 本体、音乐、个人聊天记录或 API Key。
- API 由测试者自行提供，模型调用可能收费；工作模式执行操作前会按权限规则请求确认。开启“总是允许普通操作”前请阅读界面提示。
- 首次工作需要联网下载运行环境和后端，可能耗时几分钟；下载不消耗模型 API 额度。网络失败或取消后，重新开始工作即可重试。
- B站及网易云网页登录仍依赖 Windows 的 Microsoft Edge WebView2 Runtime；网站账号与播放权限由平台决定。
- 需要 Git 或其他项目开发工具的任务，仍需电脑具备相应工具。自动准备提供 Agent 本身的运行环境，不包含所有语言开发工具链。
- 本包为未签名测试版，尚需其他电脑反馈。安装前从托盘退出旧桌宠。
