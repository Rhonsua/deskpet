洛天依桌宠 0.7.2

互动养成增强包 0.3.2
「成长纪念集 → 上河图」从第 1 幅开始，随每日有效互动逐幅收集。共 18 幅，每天最多获得 5 幅。旧档会补算已记录的互动，并保留拼好的画片。已有 0.7.2 的玩家可单独更新 Mod。

本次更新
1. B站歌单支持将选中视频或全部分 P 下载为 MP3。每 P 保存为单独文件，完成后加入本地「B站下载」歌单；同名文件会询问是否覆盖。转换工具首次使用时单独准备。
2. 改进摸头互动的接触区域和手套反馈，优化提起、放下与鼠标互动的衔接；缺少支持动作的角色仍按其可用能力响应。
3. 安装包使用新的压缩方式，减少下载体积；安装时会临时解压数据，实际大小随版本内容变化。
4. 优化首次进入聊天、音乐页面和图片加载时的响应；音频设备和部分资源在需要时准备，首次使用仍可能需要等待。
5. 主程序新增互动养成 Mod 所需的通用接口。独立的「互动养成增强包」提供每日陪伴、亲密度、节奏演出、猜歌、三曲小演出与成长纪念集；纪念集以可拖动的独立书本窗口呈现，书内可翻页、切换章节及导出纪念卡。

安装与更新
适用于 Windows 10 / 11（64 位）。从托盘退出旧桌宠后，安装 0.7.2 主程序；原有歌单、成长记录、聊天和背景保留。0.6.2 及之后版本也可在「打开歌单 → 设置 → 版本与更新」检查更新。

互动养成增强包是独立附件，不包含在主程序安装包中。先安装 0.7.2，再在「扩展功能 / Mod」中点击「打开 Mod 文件夹」，将附件中的 bond 文件夹解压到该目录，确认 bond/mod.json 和 bond/entry.py 直接位于其中；重启桌宠后启用「互动养成增强包」。停用不会删除养成记录。仅安装并启用可信来源的 Mod。

安装包不含个人音乐、聊天记录、API 配置、语音模型或 GPT-SoVITS 环境。B站网页播放需要 Microsoft Edge WebView2 Runtime；网站登录和验证仍需在网页中完成。
