洛天依桌宠 0.6.3

本次更新
1. 新增普通酷狗音乐：搜索歌曲、扫码登录、读取个人歌单、播放与同步 LRC 歌词。
2. 酷狗和网易云共用在线音乐页面，在顶部切换平台；浏览另一个平台时不打断当前播放，点歌后切换音源。
3. 修复酷狗已登录却无法读取歌单的问题，兼容实际返回格式；重复分页和中途失败保留已读取结果并提示。
4. 共用歌词显示、节拍跟随、歌单下载和 LRC 绑定流程；账号、缓存、下载目录及页面背景位置按平台分别保存。
5. 保留原网易云、本地 MP3、B站、陪伴和工作模式，以及 0.6.2 的 GitHub 更新检测。

使用说明
- 打开歌单 → 在线音乐 · 网易云 / 酷狗 → 顶部选择“酷狗”。使用普通酷狗音乐 App 扫码，并在手机确认。
- 无需安装酷狗电脑客户端或部署额外接口。已验证真实账号歌单读取、歌曲列表，以及匿名搜索、歌词和免费音源请求。
- 下载只提供接口明确授权的免费完整音源；付费/VIP、试听曲目及部分旧分享链接可能不支持。下载后的 MP3 加入本地列表，LRC 自动绑定。
- 0.6.2 用户可在“设置 → 版本与更新”检查、下载更新；更早版本请手动下载安装。
- 先从系统托盘退出旧桌宠，再运行 TianyiPet-0.6.3-Setup.exe，覆盖安装到原位置。保留个人设置、音乐列表、聊天与工作会话。
- 安装包仅含当前洛天依素材和通用扩展接口，不含 Miku、Mod 本体、个人音乐、背景、聊天记录或 API Key。
- Windows 10 / 11 x64；工作模式仍按需准备 Node.js 和官方 Harness 后端，已安装的后端直接复用。
- 本包为未签名发行包，更新检测及下载需要能够连接 GitHub。
