洛天依桌宠 0.6.1 测试版

1. 工作模式改为项目与对话侧栏，右侧上方显示消息、底部固定输入框。同一项目可保留多段独立对话、草稿和工作会话，窄窗口自动收起侧栏。
2. 进入工位、切换对话或重启恢复时，默认定位到最后一条消息，仍可手动向上查看历史。
3. 新对话入口不再同时重复显示。同一项目已有未使用的空对话时，点击“＋ 新对话”直接切过去；关闭窗口或退出后不保留空占位。旧空对话会自动清理，草稿、历史消息和工作记录继续保留。
4. 新增背景位置调整：可拖动预览或用左右、上下、缩放滑块选择显示区域。各页面独立保存裁剪位置和缩放比例，切页、重启后保留。
5. 修复网易云工具页面缺少背景的问题。歌单与网易云、歌词、节拍窗口共用音乐背景图片，各页面可单独调整构图；音乐背景与聊天背景分开保存。
6. 保留原有半透明界面外观，并整理程序目录与文档结构。

安装说明
- 从系统托盘退出旧桌宠后，运行 TianyiPet-0.6.1-Setup.exe，可覆盖安装到原位置。个人设置、歌单、聊天记录及工作运行环境保存在用户数据目录。
- 延续 0.6.0 的自动工作环境准备：首次工作先下载并校验 Node.js，再安装匹配的官方 DeepSeek Harness 后端，完成后继续任务；已准备好的环境可复用。
- 安装包仅含当前洛天依素材和通用角色、人格及 Mod 接口，不包含 Miku、Mod 本体、个人背景、音乐、聊天记录或 API Key。
- 模型 API 由使用者自行配置。网易云和 B站网页登录依赖 Microsoft Edge WebView2 Runtime。
- 本包为未签名测试版。
