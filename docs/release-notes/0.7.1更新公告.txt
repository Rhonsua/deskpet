洛天依桌宠 0.7.1

本次更新
1. 新增框选自由活动范围。在「休息 → 框选活动范围」拖出矩形即可保存，散步、蛄蛹和上下移动都遵守范围。手动拖拽不受限制；拖出范围会暂停移动，拖回后继续。支持重新框选和恢复全桌面。
2. 修复 B站开始播放几秒后被拉回开头、恢复播放重复听到开头的问题，避免重复执行重播指令。增加合集、UP 主合集与登录账号收藏夹的一键导入；本地和 B站歌单均支持倒序及上下调整歌曲。
3. 聊天支持文字与表情一起发送、GIF 动图及模型主动发表情，内置天依和阿绫表情。文字可朗读，表情单独显示、不进入语音合成；聊天默认定位到最新消息，缩小表情占用空间。
4. 丰富天依的基础设定、歌曲知识与回复方式，按话题召回相关记忆。陪伴模式可启用联网查询，主动聊天频率可调；拖动等互动不再打断正在播放的语音。
5. 增加主面板的轻量聊天输入，保留「和我聊天」完整入口；改进点歌与聊天意图区分，减少把普通聊天误识别成动作指令。
6. 汇总此前 0.7.0 同版本修订：优化部分电脑的 API 连接兼容性，工作模式支持 Markdown 与数学公式，发送后清空输入框，任务执行中可补充指令。

安装与更新
适用于 Windows 10 / 11（64 位）。0.6.2 及之后版本可在「打开歌单 → 设置 → 版本与更新」检查新版，也可直接下载本页安装包。先从托盘退出旧桌宠，再安装到原位置；原有歌单、成长记录、聊天和背景保留。

安装包含内置天依角色及表情，不含语音模型、GPT-SoVITS 运行环境、Miku、其他自定义角色和 Mod 本体。原有语音包可继续使用；语音环境安装助手仍可从 0.7.0 发行页获取。

本次发布进行了快速回归与构建检查，未执行长时间或高负载测试。首次使用或遇到问题，欢迎在仓库 Issues 反馈。
