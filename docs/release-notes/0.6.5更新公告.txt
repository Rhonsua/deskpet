洛天依桌宠 0.6.5

本次更新
1. 新增“本地 / B站轮流循环”：当前本地歌单与 B站歌单各播放一首，依次轮换、循环继续。音乐页和 B站页开关同步，重启后保留设置和轮换位置。
2. 上一首、下一首支持跨本地和 B站切换；某一边为空时继续播放另一边，自动跳过失效的本地文件。关闭轮流循环后恢复两边原来的播放模式。
3. 修复重启后选中歌单和旧播放队列不一致的问题。新增“播放此歌单”，选择另一首歌或歌单后点击播放会使用新的选择。
4. 修复歌曲停在末尾时恢复播放可能无效的问题；保存进度异常时也能恢复。本地继续上次进度，已播完的歌曲从头播放；B站记住上次视频，点击后从头播放。
5. 修复 B站首次加载期间播放 / 暂停指令可能丢失的问题，并处理暂停时迟到的结束消息，避免误切歌。
6. 保留 0.6.4 的酷狗、网易云、MP3 与 LRC 下载、歌词、节拍跟随、陪伴与工作模式。

使用说明
- 打开歌单 → 音乐，选择本地歌单，并在 B站页添加视频，勾选“本地 / B站轮流循环”后开始播放。也可以从 B站开始。
- B站一个视频链接算一首，合集内部歌曲不拆分；网页要求登录或确认播放时仍需在播放窗口完成。
- 重启只恢复记录，不会自动播放音乐或打开 B站窗口。网易云和酷狗不参与本次轮流播放。
- 0.6.2 及以上版本可在“设置 → 版本与更新”检查更新；这是完整安装包，覆盖安装到原位置即可，不是增量补丁。
- 安装前从系统托盘退出旧桌宠。保留个人设置、歌单、音乐文件、背景、聊天与工作会话。
- 安装包仅含当前洛天依素材和通用扩展接口，不含 Miku、Mod 本体、个人音乐、背景、聊天记录或 API Key。
- Windows 10 / 11 x64；工作模式按需准备 Node.js 和官方 Harness 后端，已安装的后端直接复用。
- 本包为未签名发行包，更新检测和下载需要能够连接 GitHub。
