# 酷狗与网易云共用音乐页

此功能包含在 **0.6.4 安装包**。0.6.2 用户可通过桌宠内的“检查更新”下载安装新版。

## 使用

打开歌单，点击「在线音乐 · 网易云 / 酷狗」。在同一个在线音乐页顶部选择「网易云」或「酷狗」，无需另开窗口。歌词字幕、节拍跟随、背景更换和位置调整仍在原窗口。

切换平台只切换浏览页面，当前歌曲继续播放；点击另一平台的歌曲后才切换音源。账号、歌单快照、歌词来源、下载目录和每页背景构图分别保存。网易云原来的登录与数据继续使用。

酷狗支持普通酷狗音乐 App：

1. 在「歌曲与歌单」输入歌名、歌手，点击搜索。双击歌曲播放，也可播放整个当前列表。
2. 在「我的歌单」点击扫码登录，用普通酷狗音乐 App 扫码，并在手机确认。界面分别显示等待扫码、已扫描待确认、登录成功和过期状态。登录成功后读取歌单，可选本机加密记住登录。
3. 歌单分享内容可以粘贴到搜索框。程序识别官方 HTTPS 链接、歌单全局标识和受限的官方跳转；无法解析时保留原列表并提示。旧版纯数字歌单链接和部分短链可能不适用，优先使用登录后的「我的歌单」。
4. 播放会自动获取 LRC 并使用实际播放进度同步。歌词颜色、显隐、位置设置与原有功能共用。也可为本地或 B站的同版本歌曲确认绑定。
5. 「下载歌曲＋LRC」或「一键下载整个歌单＋LRC」会让用户选择文件夹，已有同名文件会询问覆盖或跳过。成功下载的 MP3 加入本地歌单，LRC 自动绑定；其他受支持音频格式保存到文件夹，不假装已导入只支持 MP3 的本地列表。
6. 「节拍跟随」继续只有一个主开关。完整可播放音源首次分析后缓存，缓存按平台、歌曲和音频版本分开；试听片段跳过自动分析，失败仍可听歌。

不需要安装酷狗电脑客户端、Node.js，也不需要填写接口地址或 Cookie。音乐登录与聊天 API 配置互不相关。取消、切歌或退出账号后，旧请求不能重新播放或恢复旧登录状态。

## 当前验证范围

已经用匿名请求核对搜索、LRC、二维码生成和等待扫码状态、公开歌单分页、免费完整音源的播放与下载请求。已做共享页面、请求取消、平台切换、歌词/节拍缓存隔离及原网易云回归检查。

已用本机保存的真实登录信息验证个人歌单列表及歌单内歌曲读取。普通酷狗的个人歌单返回在 `data.info`，可能没有 `total/count`；按原始页长度继续分页，不把分类计数错误地当作总数。重复页、格式异常或后续页失败保留已读结果并标记为部分结果。手机扫码确认过程仍由用户实际操作。

付费/VIP下载暂不做可用承诺；只保存接口对当前账号返回的完整音频，MP3 获取路径见下文，不将试听片段当成完整歌曲。失败曲目会记录原因，部分歌单不会标为完整，失败刷新不覆盖上次完整快照。

只接受已核对的酷狗 HTTPS 音频服务器。部分旧短链接口存在 HTTPS 证书域名不匹配，本版不会忽略证书错误；可改用「我的歌单」或新版完整链接。

## 实现与归属

### 0.6.4 的 MP3 下载修复

普通酷狗可能在下载入口不返回地址，但当前账号的正常播放入口能提供完整、未加密的 MP3。0.6.4 先尝试下载入口，未取得完整音源时再尝试保存这个播放流；仍使用同一账号与标准 128 音质，不改会员状态，不把试听片段或加密文件保存成完整 MP3。下载入口明确成功时不再要求搜索接口专有的 `pay_type` 字段。

已用本机账号实际保存 3,841,290 字节的 MP3，并读取音频元数据确认时长 240 秒、码率 128 kbps。免费样本的下载入口亦可实际保存 MP3。两个返回的官方音频域名均通过 HTTPS 音频头检查，播放主线路失败时尝试备用线路；最终失败保留具体原因，便于区分曲目不可用、接口拒绝和网络加载错误。此轮没有增加“MP3 失败后仅保存 LRC”的降级操作。

酷狗协议参考 [MakcRe/KuGouMusicApi](https://github.com/MakcRe/KuGouMusicApi)，其 [MIT 许可证](../../deskpet/music/kugou/LICENSE) 随源码及后续安装包保留。只接入所需音乐功能，不执行上游其他账号或权益操作。

代码分为 `deskpet/music/kugou`（接口与酷狗页面）、`music/tools/platform_widget.py`（共用平台切换），以及共用播放、下载、歌词和节拍模块。用户数据放在桌宠数据目录的 `music-companion/kugou`；登录凭据使用 Windows 本机加密。
