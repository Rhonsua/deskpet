# 工作模式与项目对话

聊天窗口切到“工作模式”，左侧是项目和对话，右侧上方显示消息，底部固定输入任务。界面继续使用聊天窗口设置的背景和半透明控件。

1. 点击“添加项目文件夹”，选择要处理的目录。
2. 在底部输入任务，按 Enter 或点击“发送”；Shift+Enter 换行。中文输入法选字时不会误发送。
3. 同一项目可点击“新对话”开启独立会话；点击侧栏的旧对话可继续之前的任务。进入工作页、切换对话或重启恢复时，默认显示最后一条消息；之后可以手动向上翻阅历史。
4. 思考、调用工具、文件变化收在“工作详情”中。需确认的操作单独显示，允许或拒绝按钮始终可见。
5. “工作设置”中可调整普通操作自动审批；开启时先显示范围提醒，高风险操作仍需确认。

切换项目或对话不会停止后台任务。当前最多同时运行一个任务；查看别的对话时，可点击“返回正在工作的对话”。点击“停止工作”才会取消任务。工作动作预览与任务独立，再次点击可结束预览。

项目目录、每段对话的历史、草稿、审批模式及上次选择会自动保存。关闭窗口后可以重新进入；退出程序后不会自动执行未完成的任务。后端记录不可用时保留页面历史，提示重新开始。

窄窗口会自动收起左栏，可用右侧顶部的“项目”按钮展开；宽窗口可拖动分隔线调整侧栏宽度。窗口收缩不会把输入框滚出页面。

## 调整背景显示区域

先在窗口顶部点击“更换背景”，再点击“调整位置”。可以按住左键拖动预览图，或使用“左右位置”“上下位置”“放大”滑块微调；预览范围与当前窗口比例一致，背景同时实时更新。图片刚好铺满某个方向时，可先放大一点再移动。

点击“保存位置”后记住设置，重启继续使用；“取消”或关闭调整窗口会恢复原来的位置。“居中并重置缩放”回到默认构图。更换图片或恢复默认背景会重置位置。背景仍铺满整个聊天窗口，陪伴和工作页共用这项外观设置，图片不发送给模型。

## 存档与旧版迁移

页面存档仍为应用数据目录中的 `work-projects.json`。新版格式为 version 2：每个项目可以包含多段对话，每段对话有独立的后端会话编号。第一次读取 version 1 存档时，将原项目会话转换为一段历史对话，并保留一份原始 `work-projects.v1.backup.json`。

这项界面迁移不移动后端运行环境、会话目录或人物素材。损坏的页面存档不会被空白页面覆盖。源码和安装版是独立程序，更新源码后需要重新启动；现有安装包不会因 Git 更新自动改变。
