# 本地与 B站轮流播放

在「歌单与设置 → 音乐」或「B站」勾选 **本地 / B站轮流循环**。两处开关同步，重启后记住设置。

- 顺序为：本地第 1 首 → B站第 1 首 → 本地第 2 首 → B站第 2 首，分别播完后循环。
- 本地使用当前选中的歌单，B站使用已添加的视频歌单。可以从任意一边开始；点播某首会从这首接着轮换。
- 「上一首 / 下一首」也支持跨两边切歌。缺失的本地文件会跳过；某一边为空时继续播放另一边。
- 关闭开关后，恢复两边原有的顺序、循环或随机模式。网易云、酷狗不参加这项轮流播放。
- B站一个视频链接算一首；合集视频内部的不同歌曲不拆分。B站仍可能要求在播放窗口完成登录或确认播放。

## 重启和选歌

- 重启只恢复歌曲、歌单归属、音源和轮换位置，不自动出声，也不提前启动网页。
- 本地歌曲继续上次进度；若已在末尾则从头播放。B站恢复上次视频，点击播放后从头开始。
- 改选本地歌单或单击另一首歌后，音乐页「播放」优先播放新选择。「播放此歌单」可明确切回当前本地歌单。
- 播放网页首次加载时，播放/暂停意图随加载指令一起送达，避免按钮在准备阶段失效。

这次修改保留现有歌单、文件和独立播放模式，不需要重新导入音乐。
