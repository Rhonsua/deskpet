洛天依桌宠 0.5.0 更新公告

1. 优化界面流畅度
优化 API 首次加载与聊天请求的处理方式，后台加载可与桌宠动作同时进行，减少打开相关界面、等待回复时的卡顿。

2. 优化边缘收起效果
调整桌面边缘吸附、探头与收起过渡，缓解收起动作僵硬的问题，拖出和展开更自然。

3. 新增互动与散步动作
新增 Live2D 摸头反馈和左右侧身散步，支持手动散步与随机游走；随机触发后至少冷却 10 分钟，可随时通过交互打断。同步优化交替迈步、步幅、摆臂及行走速度。

4. 更新拖起动作
提起天依时改为「> <」闭眼、挥动手臂的反应，并优化拖动时的左右摇晃。松手后恢复原有状态。

5. 优化歌词位置
歌词保持与桌宠的相对位置，移动到屏幕边缘时也继续跟随，减少歌词与角色错位；保留字号、颜色、位置调整和右键隐藏等设置。

使用说明：提供 Windows 安装包和免安装压缩包。先退出旧版桌宠，再运行安装包，或完整解压到新文件夹后运行 TianyiPet.exe，请勿直接在压缩包中运行。
主程序包含洛天依及 Mod 接口，不包含 Miku、Mod 本体、歌曲或个人数据。

音频修复补充：缩短系统输出设备的兜底检测间隔，切换耳机或扬声器时优先保留当前歌曲和缓冲，避免每次重新加载；保留播放进度和暂停状态，并为输出切换后播放停滞增加自动恢复。
