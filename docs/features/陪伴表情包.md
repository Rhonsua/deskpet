# 陪伴表情包

## 使用

- 在陪伴聊天输入框下点 **表情**，选图后先加入待发送区并显示缩略图。可以先打字再选图，也可以先选图再打字，最后按 Enter 或点 **发送**，文字和表情作为同一条消息发出；不写文字则只发表情。点外面或按 Esc 收起面板。
- 面板提供最近、收藏、天依、阿绫、我的五个分组。右键可收藏或选择“立即单独发送”，不会清空未写完的草稿。**移除表情**仅移除附件，保留文字；组合消息发送失败时恢复文字和表情。
- 聊天记录里的表情最长边为 96 像素，桌宠气泡为 128 像素，待发送缩略图为 48 像素；静态图和 GIF 等比例显示，小图不放大，原始文件不变。
- 打开或重新进入聊天页默认显示最底部的最新消息；在底部调整窗口大小时继续保持底部，向上翻阅历史时不会被流式回复拉回。
- 内置洛天依、乐正绫各 20 张。图片保留透明背景，512 像素 WebP，总计约 2.8 MiB。
- 面板右上角 **+ → 导入图片 / GIF** 支持 PNG、JPG、WebP 和 GIF。鼠标悬停放大预览；GIF 保留原始动画，在悬停预览、聊天气泡和桌宠气泡中播放。聊天最近最多 8 种 GIF 同时播放，页面隐藏时暂停。
- 天依可根据聊天语境自行选表情，也可直接要求“发一个你自己的抱抱表情”。一次 API 回复可以选择发多条文字与独立的表情消息，按返回顺序分开显示，不因分条而多次请求模型。
- 语音与表情分离：只把文字消息按顺序交给语音合成；图片、表情编号、消息标签不参与朗读。开启朗读时，合成准备好后显示本轮消息并播放语音；只有表情时立即显示，不启动语音。唱歌、播放音乐指令继续跳过语音。
- 主动聊天也可使用内置或已识别的表情，不在空闲时主动联网找图。

## 看图与网络搜索

- 内置图片身份经过标注，无需额外看图模型，普通文本 API 也可使用。
- 点击发送内置表情时，角色与情绪说明直接附在本轮用户消息中，不只放在背景资料里。即使没打字，模型也能收到“乐正绫·努力中”等有效内容；它依据已确认说明理解表情，不会因此获得屏幕或任意图片的视觉能力。
- 导入的未知图片不会仅凭文件名标成天依。发送未知图片会把首帧缩略图交给看图模型；也可右键自定义表情选择“识别图中角色”，保存角色与情绪标签。
- API 设置新增“看图模型”，使用同一接口和 Key，留空使用当前模型。如果当前模型不支持图片，需要填写同服务商提供的看图模型；不会悄悄调用其他服务。
- 开启“允许天依联网找表情”后，AI 可以提出搜索要求；表情面板切到天依或阿绫、填写关键词后，可通过 **+ → 联网找表情** 手动搜索。
- 网络图通过公开搜索页面获取候选，并由看图模型核对角色、情绪和适宜性。角色不符、识别不确定或置信度低于 0.85 时不自动发送。模型识别仍可能出错，不能保证百分之百准确。
- 网络搜索受搜索网站、网络和图片源可用性影响。搜不到或看图失败会提示原因，内置图片仍可用。没有验证码绕过、账户登录或付费图片获取功能。
- 网络图片消息保留“图片来源”入口。消息中只能引用已验证的本地表情编号，不能由模型任意提供路径或图片网址。

## 文件与限制

- 内置目录：`assets/stickers/`，清单 `catalog.json`；安装包显式包含清单引用的 40 张压缩图。
- 用户导入与联网确认后的图片存于桌宠数据目录的 `chat/stickers/`，升级不会覆盖。
- 最近使用、收藏保存在此目录的 `panel.json`；最近最多 40 张。
- 用户图库上限 200 张；单图 12 MB，最长边 4096 像素，GIF 最多 400 帧。
- 历史记录只保存表情编号；发给 API 的旧历史使用角色与情绪说明，不反复上传旧图片。
- 多条消息仍作为一轮对话保存，重开聊天后保持分条与顺序，不挤占“最近 6 轮”的对话额度。
- 发给模型的助手历史保留 `[消息]`、`[表情:编号]` 格式，与新回复一致；不再把内部图片说明当作天依过去说过的话。旧版误输出的“已发送的表情包”注释会在显示与朗读前清理，能唯一匹配已确认图片时恢复为图片，匹配不到时不猜图。原始聊天记录保留，无需清空聊天。
- 全尺寸生成原图不进入安装包。角色图片继续按本项目约定留在本机，代码仓库只包含目录清单和生成、压缩记录。

## 制作记录

使用内置图像生成工具分别生成 40 张原始表情。天依以现有 `tianyi-refined-v3-smooth.png` 为身份参考，纠正第一次生成中误加的编织辫和服装纹样后，再固定修正版生成其余表情。阿绫使用红棕发、红眼、单长麻花辫与经典红白服装。

每张维持统一的 Q 版头像和上半身、细描边、透明背景，不在图中生成文字。分别改变姿势和表情：你好、开心、笑哭、害羞、喜欢、抱抱、加油、谢谢、疑惑、思考、震惊、哼、委屈、累了、困困、饿了、好吃、听歌、努力中、晚安。

生成提示模板：固定参考图的脸型、发型、发色、眼睛和公式服；只改变对应情绪的面部与手部姿势；单人上半身贴纸，全部头发和手完整入画，细白描边，真实透明通道，不添加文字、水印或背景。每张的具体姿态见 `assets/stickers/prompts.json`。

压缩工具 `packaging/prepare_stickers.py` 将图缩到最长边 512，输出 quality=87 的 WebP 并检查透明通道。40 张从 70,348,436 字节压至 2,920,486 字节，缩减约 95.85%。
