# 天依头像图标

- `tianyi-avatar.png`：参照项目现有精致版角色图，通过 imagegen 生成的透明头像，1254×1254。
- `tianyi.ico`：从头像机械转换，包含 16、20、24、32、40、48、64、128、256 像素九档，保留透明通道。

制作要求：灰发绿眼，后脑上方八字环辫，蓝色丝带，正面笑脸，少量经典 V3 领口，轮廓清晰，无文字、无背景。参考为 `assets/character/tianyi-refined-v3-smooth.png`；没有修改桌宠本身的动作素材。

`app_icon.py` 统一加载 ICO，应用窗口与系统托盘共用；PyInstaller 配置同时嵌入 EXE 图标和运行时资源。源码桌面快捷方式的图标地址设为此 ICO。正在运行的旧进程需退出后重开；既有安装包需重新构建才能包含更新。

这是非官方同人图标，角色及相关标识权利归相应权利人；项目代码许可证不代表获得角色形象授权。
