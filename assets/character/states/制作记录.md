# 互动状态素材

日期：2026-10-17

制作方式：内置 imagegen 编辑模式，使用 `../tianyi-refined-v3-smooth.png` 为唯一目标，保持精致版画风、平滑发环和经典 V3 公式服。

| 文件 | 用途 |
| --- | --- |
| `blink.png` | 眨眼与闭眼休息 |
| `happy.png` | 摸头/挥手回应与升级 |
| `eat.png` | 投喂抱包子 |
| `lift.png` | 提起与戳一戳回应 |
| `sleep-back.png` | 背对观众侧躺盖被子睡眠，只露后脑和背侧头发 |
| `phone.png` | 被窝熬夜玩手机 |

各文件保留透明通道。运行时统一脚底锚点，以状态切换配合连续呼吸、旋转、摆动、回弹和程序特效。这些不是完整逐帧动作序列。

睡眠、手机为后续横向卧姿素材，沿用底部锚点，另按横向区域适配；来源与完整提示词见 [睡眠与手机制作记录](睡眠与手机制作记录.md)。

`sleep.png`、`sleep-v3.png` 保留为旧版对照，程序使用 `sleep-back.png`。
