# 经典 V3 公式服修正

日期：2026-10-17

用户明确选择经典 V3 公式服。服装修正应用到圆润、精致两种画风，保留既有脸型和身材比例。旧版文件保留。

## 参考来源

- [Vsinger 官方人物页](https://vsinger.com/vsinger)：核对角色版本与公开素材入口。官网图片资源本轮返回 AccessDenied，未将不可访问的资源当作已读取的参考。
- [ideolo V3 人设图转载页](https://www.zerochan.net/1142879)：实际读取并作为本轮服装参考。
- 本地参考：`../references/v3-design-ideolo.jpg`。该图仅为服装参考，不作为桌宠成品。

## 核对要点

1. 分离白领、绿色圆形碧玉、黄色领带。
2. 蓝色分离袖，外侧白色圆盘与绿色中心；黑色贴身袖套和白袖口。
3. 白色主体、蓝色包边与裙摆，腰侧黄色装饰及红色中国结。
4. 黑色不对称袜：正面看左侧为及膝袜，右侧为过膝袜；蓝色袜口。
5. 不对称蓝白靴，保留原设定配色。
6. 头顶蓝白花饰与耳侧装置依据设定图调整。

## 输出与使用

- `tianyi-simple-v3-costume.png`：圆润 Q 版。
- `tianyi-refined-v3-costume.png`：精致 Q 版。
- 工具：内置 imagegen 编辑模式，每次输入一张原角色图（编辑目标）与一张 V3 设定图（服装参考），透明背景。
- 本轮为公式服 Q 版改绘，非官方原画；表情、衣服结构和饰物仍需在后续逐帧制作时持续校准。
