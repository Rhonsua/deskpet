# 洛天依桌宠

Windows 音乐桌宠，支持本地 MP3、网易云／酷狗歌单与 B站网页播放，可配置自己的模型 API 进行文字聊天。默认使用经典 V3 公式服 Live2D 洛天依，也可切换静态模型或自定义 PNG 角色。

### 陪伴与工作模式

打开“和我聊天”：在陪伴页分别启用“主动聊天”和“小动作”；默认关闭。主动聊天使用已保存的聊天 API，只有桌宠空闲、操作窗口关闭后才会尝试。用户拖动、摸摸、休息、播放音乐等操作优先。

也可以直接对她说“挥挥手”“去睡觉”“醒醒”“玩手机”“拿麦克风唱歌”“往左走一走”或“停止散步”。固定口令在本机立即处理；其他自然说法由已配置的 API 理解并选择动作，例如“钻进被窝小睡一阵”“朝上面挪开一点”“给我表演认真敲键盘的样子”。输入“你会什么动作”查看当前模型支持的动作，包括庆祝、吃东西、工作预览、左右散步、上下挪动、烟雾瞬移和停止动作。每次回复最多执行一个动作，流式输出过程中不提前执行，取消或状态改变后不执行迟到请求。

摸头、拖起、放下和鼠标跟随仍由鼠标互动控制。模型缺少动作或正在进行优先级更高的互动时，会说明原因。唱歌只切换持麦动作，歌曲仍由歌单播放；吃东西和庆祝仅表演，不修改音符、饱食或等级；工作动作预览不启动或停止实际工作任务。自动主动聊天保持文字陪伴，不自行使用这些用户指令权限。

陪伴页新增“恢复平时状态”按钮：停止当前临时动作、退出休息/手机/唱歌姿势和工作展示，保留正在播放的音乐及后台工作任务。等待 AI 回复时点击也会取消旧请求，避免迟到动作再次改变状态。

可以说“播放本地歌单”“播放 B站歌单”“暂停音乐”“继续播放”“上一首”“下一首”或“停止播放”。“播放＋歌名”会先搜索真实歌单；API 也可按歌名正则点播，例如“播放本地匹配 `^流光$` 的歌”“播放 B站匹配 `普通DISCO` 的歌”，还可指定准确的本地歌单名。未指定音源的点歌会搜索本地与 B站已保存的歌单；一首匹配直接播放，多首时由已配置的 API 根据你的描述选择版本。选歌只发送最多 60 条候选的标题、来源、歌单名与临时编号，不发送文件路径或播放网址。找不到、文件失效、表达式错误或搜索超时都会明确提示。普通播放使用当前歌单或所选歌曲；B站登录、验证或自动播放限制仍需在播放网页处理。

本地歌单新增独立的原子保存文件与一份非空备份。配置损坏时优先恢复备份；没有可用备份则保留损坏记录并停止覆盖，不再自动把空歌单写回。另一个实例更改过歌单时，旧实例也会停止覆盖并提示重开桌宠。备份只保存歌曲路径，不复制或删除 MP3 文件。

0.6.5 新增「本地 / B站轮流循环」：当前本地歌单与 B站歌单各播一首，轮流循环；开关和轮换位置会保存。修复重启后选中歌单与旧播放队列不一致、歌曲末尾恢复以及 B站首次加载时播放/暂停无效的问题。使用方法见 [本地与 B站轮流播放](docs/guides/本地与B站轮流播放.md)。

“你给我唱一下《反乌托邦》”“唱首《流光》”也会按歌名点播已有录音；没有歌名的“唱一下”只执行唱歌动作。“切到B站”“切回本地”直接切换并播放对应歌单；“给我播放b站合集”会搜索标题包含合集、合辑、歌单或串烧的视频，多结果仍由 AI 选择。

工作模式采用左侧“项目与对话”、右侧消息记录、底部固定输入框的布局。添加项目文件夹后，可在同一项目下新建多段独立对话；Enter 发送，Shift+Enter 换行，中文选字不会误发送。切换对话时保留历史、草稿和后端会话，窄窗口自动收起侧栏。工具记录收进“工作详情”，需要确认的操作单独显示。详见 [工作模式与项目对话](docs/guides/工作模式与项目对话.md)。工作模式复用“API 设置”中已保存的 DeepSeek 官方模型配置，不套用陪伴模式的难题拒答规则；第三方兼容聊天接口暂不直接用于工作模式。切换页面不停止任务；停止任务或退出桌宠会清理后台进程。任务运行期间暂停主动陪伴。

安装包用户首次发送工作任务时，程序先下载并校验官方 Node.js 免安装版，再用其自带的 npm 安装匹配版本的官方 Harness 后端。显示准备进度，可停止或失败后重试，完成后继续当前任务；以后直接复用。无需手动安装 Python、Node.js、Harness 桌面端，也无需打开网页。后端与会话分别保存在用户数据目录的 `work-runtime`、`work-sessions` 中，不依赖官方 DSH 安装目录，也不修改系统 PATH。源码用户先运行 `packaging/setup_harness.ps1` 准备隔离的 SDK 环境。

文件读写、命令执行和审批由官方后端处理，桌宠提供原生界面。内置天依 Live2D 已接入 PSD2Live 工作姿势：任务执行时敲键盘、轻摆腿，等待审批时停下，结束后恢复原状态；拖动、摸摸、睡觉和音乐播放优先。工作页的“预览工作动作”可播放 20 秒，再次点击停止，不调用 API。详见 [双模式说明与动作计划](docs/design/陪伴与工作双模式方案.md)。

陪伴对话中明确要求散步时，按手动指令执行，不受随机游走冷却限制，也不会消耗或重置随机冷却；当前互动和活动边界仍然生效。

工作动作已补充可见的手腕与指尖敲击、眨眼和局部呼吸；等待审批时眨眼、呼吸继续。动作按“直接互动 → 手动指令 → 工作表现 → 自动动作 → 待机”分级，详见 [动作优先级](docs/design/动作优先级.md)。工作页支持添加项目、切换独立页面，保存各项目的多段会话、输出及草稿，重启恢复上次对话；同一时刻最多执行一个工作任务。

工作页提供“总是允许普通操作（高风险仍需确认）”，默认关闭，按对话保存。开启时弹出范围提醒：官方 Harness 会额外调用 API 审查工具操作，普通操作自动执行，高风险或未获授权的操作仍等待手动确认，审查失败不执行。此模式不限制在项目目录内，模型风险判断也并非绝对可靠；任务进行期间锁定开关，结束后可关闭，继续旧会话也会按当前设置执行。

聊天窗口右上角显示当前 DeepSeek 官方 API 账号余额，含赠金与充值余额；悬停可查看明细和更新时间，点击可刷新。页面打开时查询，显示期间每分钟更新，对话结束也会尝试刷新（短时间内合并请求）。查询在后台进行，失败时标明旧余额待更新；切换服务或 Key 会清除旧显示。自定义或中转接口暂不支持余额查询。使用 [DeepSeek 官方余额接口](https://api-docs.deepseek.com/zh-cn/api/get-user-balance/)，不按本地 token 估算消费。

陪伴与工作对话使用左右消息气泡，文字可选中复制。工作模式的思考、工具调用和文件变化收进“工作中…”旁的“工作详情”，默认折叠；正文显示用户消息和模型的文字输出，审批仍单独显示。工作项目保存消息及详情，兼容旧版纯文本记录。点击聊天窗口顶部“更换背景”选择本地图片，程序保存副本并随窗口大小等比缩放，铺满整个聊天窗口。四个页面共用图片，**各页的裁剪位置和缩放比例独立保存**。切到目标页点击“调整位置”，可拖动预览，或用左右、上下和缩放滑块选择显示区域；保存后重启保留，取消恢复该页原位置。消息气泡、按钮、输入框和标签使用半透明底色，文字保持清晰；“默认背景”可恢复。背景仅保存在本机，不发送给模型。

歌单与“网易云、歌词与节拍”窗口也支持整窗自定义背景，两个窗口共用音乐图片，歌曲列表和按钮使用半透明底色。每个页面都能点击顶部“调整位置”设置自己的裁剪和缩放，包括本地歌单、B站、歌词、节拍以及网易云的各个子页；切页和重启后恢复各自设置。音乐背景不影响聊天背景；“默认背景”可还原，更换图片会重置所有音乐页面的构图。主控制面板的“打开歌单”已移到“和我聊天”下方。

陪伴移动支持“往上挪一点”“往下挪一点”“左动一点”“再往右走一点”和“停下”。上下是平滑调整位置，烟雾瞬移仍只自动触发；连续移动指令可续走或换方向，不受随机冷却限制。主动聊天由所配置的 AI 结合人设、记忆、最近对话生成，需勾选聊天页的“空闲时由 AI 主动聊天”；空闲至少 45 秒、请求间隔至少 5 分钟，失败不使用固定台词替代。

## 和天依互动

启动后只显示角色。参考 [VPet 的角色工具栏与气泡交互](https://github.com/LorisYounger/VPet)，常用操作放在角色身边，歌单和设置按需打开。

| 操作 | 效果 |
| --- | --- |
| 点击角色 | 打招呼和本地对话气泡；摸摸从控制面板进入，右键退出 |
| 点身体 | 戳一戳，惊讶回应 |
| 按住约 0.28 秒或拖动 | 提起；最新 Live2D 模型以 `> <` 闭眼并上下挥臂，松手恢复原活动 |
| 拖到屏幕边缘后松手 | 自动吸附，稍后缩成探头；左右、上下边缘均支持 |
| 拖到边缘后继续往边缘推 | 不必松手，直接缩成探头吸附；按住往桌面拉回可立即解除 |
| 鼠标经过、单击或原地按住探头 | 保持吸附，不自动展开；按住并向桌面内拖动才拉出 |
| 右键或双击 | 展开/收起贴身菜单 |
| 菜单 → 投喂 | 使用音符兑换点心，播放抱包子动作 |
| 菜单 → 休息 → 盖被子睡觉 | 背对观众侧躺、盖被子、轻轻呼吸，点击唤醒 |
| 菜单 → 休息 → 熬夜玩手机 | 被窝看手机、手机微光和轻点反馈；点击收手机或选择起床 |
| 主控制面板 → 打开歌单 | 位于“和我聊天”下方，打开歌单与添加 MP3 |
| 菜单 → 音乐 | 播放控制与唱歌动作 |
| 音乐 → 拿麦克风唱歌 / 收麦 | 持麦唱歌与左右侧转、点脚；也可切回陪伴听歌 |
| 音乐 → 拿麦克风转个身 | 临时完成一轮左右侧转，随后恢复原活动 |
| 菜单 → 设置 | 开机自启、角色大小与更多设置 |

待机有呼吸和眨眼；精致版唱歌时拿麦克风，循环正面与左右侧转姿态，腿部独立轻点、屈膝、改变重心，并浮出音符。静态版为三方向素材结合程序形变，唱歌尚未使用骨骼动画；散步使用独立序列帧，尚未实现爬墙、360 度转身或完整舞蹈；点击互动使用本地台词，另可配置 API 进行文字聊天。生成图与完整提示词见 [唱歌与侧转制作记录](assets/character/states/唱歌与侧转制作记录.md)。

唱歌动作的本地演示文件为 `docs/media/singing-demo.gif`（素材另行提供）。

已修复腿部运动的条带接缝漏底：腿部先连续采样合成，再随身体整体转动，避免运动时出现横向切割线。检查覆盖三个缩放比例、四个运动阶段和身体旋转，保留左右腿独立动作与对应点击区域。

## 持续状态与临时动作

设置中可开关“空闲时随机上下瞬移”，默认开启，无手动触发按钮。它与散步互斥，仅在当前屏幕可用区域内垂直移动；睡觉、玩手机、播放音乐、吸附或工具窗口打开时不会触发。每次瞬移后冷却 10–13 分钟，重启仍保留冷却；点击、拖拽、切换活动、打开面板或关闭开关可打断，人物立即恢复可见。此效果自带前景烟雾，不受“动作背景效果”开关影响。

待机、睡觉、玩手机、手动唱歌、收麦陪听是持续状态，会保存在设置中。提起、落地、摸头、戳一戳、投喂和转身是临时动作，结束后恢复持续状态。

- 睡觉或手机 → 提起 → 松手落地 → 继续睡觉或玩手机。
- 投喂 → 提起（投喂计时暂停）→ 落地 → 接着吃完 → 返回原活动；恢复动画不会再次扣音符或重复发奖励。
- 普通待机播放 MP3 时自动持麦唱歌；如果在拖动期间暂停播放，放下后按最新播放状态显示，不会恢复已经停止的唱歌。
- 明确点击起床、收手机或切换活动，会更新持续状态。拖拽只改变临时动作；拖动中明确选择的新活动也以最新选择为准。
- 重启恢复持续状态，临时动作不会写入设置。自动跟随的唱歌取决于真实播放状态，重启仍不自动播放音乐。

## 边缘吸附与探头

停靠使用当前屏幕的可用区域，底部避开任务栏。以下距离使用逻辑像素，并随角色大小同比缩放。

- **靠边松手**：距边缘约 20 像素内贴边，约 0.9 秒后收起探头。
- **按住推入**：继续向边缘推约 24 像素，不必松手即可吸附；沿边拖动保持停靠。
- **往回拉出**：同一次按住推入的拖动中，向桌面内拉回约 36 像素解除吸附。拉出后本次松手不会又被吸回；再次主动向外推仍可吸附。
- **探头效果**：侧边稍微倾斜，露出更多脸部；收起和展开有缓动。鼠标经过、单击或原地按住不会突然展开，向桌面内拖动才拉出。
- **原状态保留**：探头时安静待机，音乐继续；睡觉和玩手机保持完整显示。互动、气泡或工具窗口打开时保持展开，结束后再收起。
- **位置与多屏**：边缘和位置会保存，缩放后仍贴边；拖入另一块屏幕时解除旧屏幕锁定。跨屏判定已有逻辑检查，真实多屏与不同缩放仍待实测。

透明画布每帧清空，避免动作切换留下旧像素；设置、快捷菜单及下拉框使用白底黑字，选中项以黑色边框标识。

精致版新增的睡眠与手机状态素材使用内置 imagegen 生成。手机姿势参考本地用户素材，图与实际提示词见 [制作记录](assets/character/states/睡眠与手机制作记录.md)。动作由独立状态图结合程序呼吸、微光与点按反馈实现。音乐可以在休息时继续播放，播放/暂停不会强制叫醒角色。

支持从文件夹加载和切换自定义角色：在“更多设置 → 角色外观”点击“打开角色文件夹”，新建角色子文件夹并放入透明 `idle.png`，点击“刷新角色”后从下拉框选择。其余姿势可按约定命名添加，也可用 `character.json` 配置名称、作者、动作路径及头部/落地锚点。切换会保存，素材缺失或损坏时保留当前画面，重启无法加载则恢复内置角色；音乐和成长记录共用。完整画布、动作要求与制作步骤见 [角色素材规范](characters/README.md)。外部角色目前支持 PNG 姿势图与程序动画，尚不支持序列帧或外部 Live2D 模型。

## Live2D 洛天依

源码版启动后默认使用“Live2D 洛天依 · 动态模型”，启动脚本会检查所需依赖；手动配置环境时安装 `requirements.txt` 即可。可在“更多设置 → 角色外观”选择“静态模型 · 精致 Q 版 / 经典 V3”。简单（圆润）版已移出可选角色，旧设置选用该版本时自动切换为精致版。切换会保存，重启后继续使用上次选择，音乐和成长记录共用。升级到这一版时，内置角色首次改用 Live2D；已选的自定义角色继续保留。安装包与最新源码的功能差异见上方“当前进度”。GitHub 仅更新代码与说明，新增 Live2D 模型、外部角色包和安装文件不随仓库发布；从仓库运行而缺少模型时会使用静态洛天依。

模型包含持麦唱歌、摆臂、左右点脚、挥手、投喂、背身睡觉和被窝玩手机。唱歌按 4.8 秒的节奏在正面与左右转向之间平滑切换；最新本地模型提起时显示 `> <` 闭眼表情，双臂上下挥动，最高略高于肩部；同时保留弹性拉伸、横向拖动轻摆与松手落地回弹。肩部和袖根随抬臂变形，避免连接处像独立贴图。持续状态的动画时钟在提起、落地等临时动作期间暂停，结束后接着播放；睡觉和手机按人物头部尺度放大显示，窗口会随姿势变宽。

唱歌腿部在没有节拍数据时按 19.2 秒轮换四段演示步法：交替点脚、慢抬脚换重心、同脚双点、带停顿收步。有节拍数据时，Live2D 的点头、轻摆头、空闲手摆臂、转身与左右脚共用播放节拍，保持持麦姿势与一只脚支撑；静态角色同步转身、整体轻摆与点脚。共用原“节拍跟随”开关，数据可来自 BPM 标签、自动分析或手动校正。

鼠标靠近时，Live2D 会自动跟随视线及轻微转头、转身，无需按住鼠标；移远后平滑恢复。按住拖动、休息、边缘吸附、打开菜单或设置时暂停；唱歌和进食优先保持自身头身动作，附近鼠标只影响视线。可在设置里关闭“靠近时看向鼠标（拖动时暂停）”。

手边静停约 1.2 秒可触发挥手回应。摸摸仅从控制面板进入，轻轻左右移动鼠标即可互动，右键或 Esc 退出；普通点击只打招呼。摸摸模式的水平判定范围扩大为原来的两倍，高度不变。持续抚摸的视觉反馈与成长奖励冷却分开，结束后继续原活动。

唱歌音符与节拍光晕、摸头爱心、挥手闪光、睡眠 Z 字及手机柔光等背景效果会随动作变化；人物轮廓内不绘制效果，动效层始终鼠标穿透，吸附或隐藏桌宠时同步隐藏。鼠标互动和背景效果均可在设置中单独关闭。具体实现和检查见 [Live2D 使用说明](docs/guides/Live2D使用说明.md)。

此版采用 live2d-py 原生渲染，需要可用的 OpenGL 环境；首次加载需要读取模型与纹理。启动加载失败自动恢复静态精致版，手动切换失败保留当前角色，运行渲染失败也自动恢复精致版。角色素材不在 MIT 授权范围内，Live2D 及其他依赖遵循各自许可证。当前为二维转向，尚无独立手指、肘腕骨架或完整侧背面转身；模型反馈与接入检查见 [使用说明与限制](docs/guides/Live2D使用说明.md)。

音乐面板新增网易云、歌词字幕和节拍跟随入口。扫码后打开歌单即可直接播放，自动同步歌词；支持暂停、上下首及四种播放模式。选中歌曲可下载音频和同名 LRC，也可只保存歌词；以当前账号正常播放／下载权限为准，试听与不可用状态会说明。

## 自定义 API 文字聊天

右键桌宠 → “和我聊天”，或系统托盘 → “聊天”。在“API 设置”填写兼容 Chat Completions 的接口地址、模型和 Key，测试连接后保存，即可连续文字对话；支持流式显示和停止生成。测试也会向所填模型服务发送请求，可能产生费用。

API 网络组件的首次加载、连接和回复解析在独立后台进程完成，与桌宠动作并行；等待时仍可拖动和互动。后续请求复用已加载的后台，流式文字合并刷新，避免频繁更新挤占动画。加载阶段也可以停止，取消或切角色后的旧回复不会写入新对话。后台随桌宠退出，Key 只经本机进程管道传递，不放入启动参数或临时文件。这不会缩短模型服务本身的生成时间。

“人设与记忆”可编辑角色 Prompt 和手动记忆，按角色保存聊天。每次只携带有限的近期上下文；接口会收到人设、记忆、当前问题，以及少量桌宠状态。Windows 可加密记住 Key，也可仅在本次运行使用。没有语音或声库依赖。

内置一套完整洛天依人格插件，侧重音乐、日常陪伴和情绪交流。明确识别的积分、证明、编程请求由本地直接婉拒，另检查模型输出，减少继续解题的情况；简单算数和日常倾诉正常聊天。已有自定义人设保留；进入人设页点击“套用角色默认人设”即可使用新版正文。外部角色可附带纯数据 `personality.json`，见 [人格插件与资料来源](docs/guides/洛天依人格资料与插件.md)、[角色接口与模板](characters/README.md) 和 [初音未来人格](docs/guides/初音未来人格资料.md)。

开心回复可触发已有动作，睡觉、拖动、进食等状态不会被聊天打断。详细使用方式、数据位置、兼容性和限制见 [轻量聊天使用与设计](docs/guides/轻量聊天使用与设计.md)，文件职责见 [项目文件导航](docs/项目文件导航.md)。API 后台并行改动已包含在 0.5.0 免安装 ZIP，旧 0.4.2 安装包不包含。发行包不包含 Miku 素材及专用人格。

## 静态序列帧散步

- 空闲待机时随机向左或向右走一小段，空间不足时调整方向或跳过；睡觉、玩手机、唱歌、吸附或正在交互时不自动触发。
- 自动触发成功后至少冷却 **10 分钟**，到期后仍随机触发；手动散步不受自动冷却限制，也不重置该冷却。
- 散步是**临时状态**，不覆盖原有活动。点击、拖动、右键、投喂或切换模式可立即打断；结束后恢复原状态，以用户的新选择优先。
- 被打断的路线不续走，已开始的自动冷却继续保留。

在“更多设置”或互动菜单的“休息”页使用“散步 / 停下”，可关闭“空闲时随机散步”。随机散步默认开启，仅对已提供完整左右动作的角色生效；托盘也可随时停止。精致静态洛天依使用左右各 8 帧的独立慢走 PNG 序列（约 1.78 秒一个双步循环），以原精致版为形象参考，小步幅、低抬脚；动作和位移共享时间，窗口在当前屏幕可用区域内加减速，接近边界停下，不触发探头吸附。首次空闲等待后随机检查，自动成功触发后的冷却为 600～780 秒；重启和切角色保留剩余冷却。

自定义角色通过可选 `walk` 字段接入，旧包不需改动。配置见 [角色包接口](characters/README.md#可选散步序列帧)。内置 Live2D 使用侧身散步，与静态序列帧共用路线控制器。具备蛄蛹模型时，每次有效向左出发（手动、自动、陪伴指令或 API）有 25% 概率改用蛄蛹动作，保留原定目的地、自动冷却和打断规则；向右及缺少该模型的角色仍正常散步。蛄蛹不再单列手动按钮。色带按实际位移留在身后，第 3 轮结束后第 1 轮开始淡出，后续依次进行，淡出持续 5 秒。设计与实现边界见 [散步方案](docs/design/Live2D侧身散步与桌面移动方案.md)。

## 目标陪伴 Mod

0.4.2 主程序只含 Mod 接口，目标陪伴单独发布为 ZIP。打开桌宠设置或系统托盘的“扩展功能 / Mod”，点击“打开 Mod 文件夹”，将目标陪伴 ZIP 中的 `goals` 文件夹完整解压到这里，重启桌宠，勾选启用。可添加目标、截止时间和待办，勾选步骤或点击“今天推进了”记录进展，也可暂停、完成或暂缓提醒。目标存档在本机保存，停用后保留。

临期、逾期或多日未记录新进展时，通过桌宠气泡提醒；**提示音默认开启**，可在“提醒设置”关闭。默认 22:00–08:00 免打扰，每日最多 3 次，两次至少间隔 120 分钟，同一目标至少间隔 24 小时。睡觉、拖动、吸附或打开工具窗口时暂缓。仅在桌宠运行时检查，进展由用户记录。

Mod 文件夹扫描只读取信息，首次安装默认未启用；启用时运行代码，后续启动恢复启用状态。Mod 可以访问本机文件，请只安装可信来源；没有权限沙箱。使用和接口说明见 [Mod 接口与目标陪伴](docs/guides/Mod接口与目标陪伴.md)。0.4.2 安装包和免安装 ZIP 不包含目标陪伴代码、Miku 或用户存档。

## 开机自启

在“右键天依 → 设置 → 开机自启”打开，或在更多设置中勾选“登录 Windows 后启动桌宠”。默认关闭。

自启只显示桌宠，不打开歌单，也不自动播放音乐，可随时取消。仅使用当前用户的 Windows 登录启动项，无需管理员权限；源码版通过项目虚拟环境的 pythonw.exe 和绝对路径启动，不显示控制台。移动项目或虚拟环境后，需重新开启一次自启。

## 鼠标穿透

在“右键天依 → 设置”或“更多设置”中勾选“鼠标穿透”，也可从 Windows 系统托盘的桌宠图标右键菜单切换。默认关闭，开启状态会保存。

开启后鼠标点击会穿过角色窗口，角色继续显示和播放动画。此时无法直接点击、拖动或右键角色；请右键系统托盘图标取消“鼠标穿透”，或选择“关闭鼠标穿透并找回天依”。歌单与设置窗口仍可操作，切换穿透不改变睡觉、唱歌等持续状态。

使用 [Qt 的 WindowTransparentForInput](https://doc.qt.io/qt-6.8/qt.html#WindowType-enum) 设置窗口输入穿透。离屏及 Windows 原生窗口检查覆盖开关同步、状态保存、重启恢复、托盘解除，以及原生穿透样式的设置与清除；不同桌面软件下的实际点击透传和长时间使用仍待确认。

## 音乐与成长

- 支持导入或拖入 MP3、文件夹当前层的 MP3。
- 支持创建、重命名、删除和切换歌单，搜索、移除和上下移动歌曲；磁盘文件保留。
- 支持顺序播放、列表循环、单曲循环、随机播放、进度拖动和音量。
- 保存上次歌曲、进度和播放方式，重启后点击播放继续；每 15 秒及关闭时保存。
- 旧单列表自动迁移；文件缺失会显示失效，播放时跳过缺失或解码失败的文件。
- 记录今日、本周、累计实际播放时长；暂停、跳进度和休眠间隔不虚增计时。
- 每 5 分钟有效播放获得 5 经验、2 音符，每日最多 100 音符（250 分钟）；静音计时但不发奖。
- 投喂恢复饱食和心情；升级触发回应。摸头心情奖励每日最多 10 次、间隔至少 60 秒，动画互动不限次。

## 蓝牙耳机与音频输出

打开“右键天依 → 设置 → 更多设置 → 音频输出”。默认“跟随系统默认输出”，Windows 默认播放设备变化时自动更新；也可以直接选择已连接的蓝牙耳机或扬声器。设备列表会自动刷新，设置下方显示当前实际路由目标。

指定设备临时断开时会回退到当前默认输出，重新连接后恢复指定设备。切换时重新加载同一首歌并恢复进度，可能短暂停顿；原本暂停的歌曲保持不播放，歌单顺序和播放模式保留。程序不改变 Windows 的系统默认音频设置。

实现依据 [Qt QMediaDevices 设备变化通知](https://doc.qt.io/qtforpython-6.8/PySide6/QtMultimedia/QMediaDevices.html) 和 [QAudioOutput 输出设备接口](https://doc.qt.io/qtforpython-6.8/PySide6/QtMultimedia/QAudioOutput.html)。本机已识别 EDIFIER K710W，静音 MP3 的实际输出设备切换、暂停进度、恢复和单曲循环检查通过；未进行耳机实际听音确认。

## B站网页歌单

为了方便大家支持 P 主，添加了 bilibili 播放功能，欢迎通过原视频收听并支持喜欢的创作者。

右键天依 → 音乐 → B站网页歌单，或在音乐窗口点击“B站”。粘贴视频完整链接后点“添加链接”，双击歌单项开始播放。

- 只接受 `bilibili.com/video/BV…` 或 `…/video/av…` 的 HTTP/HTTPS 视频地址，支持 `?p=2` 指定分 P；会移除分享追踪参数。`b23.tv` 短链接请先在浏览器打开，复制展开后的完整地址。直播、番剧及其他网站不会加入歌单。
- 使用桌宠自己的 WebView2 播放窗口。暂停、继续、上一首、下一首及播放方式在 B站页控制；同一窗口切换歌曲，顺序播放到最后一首会关闭。点击“停止”或手动关闭网页也会停止，不会自动重开。
- 点击网页标题栏的最小化按钮，或歌单中的“最小化到托盘”，网页会收起到桌宠共用的系统托盘图标，音乐继续。右键托盘选择“显示 B站播放网页”可恢复；隐藏时自动切歌不会弹出网页。关闭按钮仍停止网页歌单。
- 单曲循环在同一页面从头重播，列表循环在最后一首结束后回到第一首；隐藏到托盘也遵循所选方式。修复网页原生循环吞掉结束事件，以及自动恢复播放覆盖结束标记的问题。
- 选中歌曲、切歌、重播及重新打开视频均从零秒开始，不采用 B站的历史续播位置。开始后的 15 秒内会继续检查异常进度跳转，纠正“先回到开头，随后又被网站恢复到末尾”的情况；手动暂停、调整进度或操作网页播放器后停止此保护，尊重用户操作。
- 后台漏报结束时，若已播放且末尾不足 0.15 秒、剩余内容已缓冲，并连续 4 秒没有进度变化，会补发一次完成信号；暂停、拖动进度和缓冲不足不触发此兜底。重播会确认已回到开头，失败时最多重试三次，再重新载入当前视频一次；仍失败会提示检查网页，避免无限刷新。自动恢复保持托盘隐藏状态。
- 切歌依据网页视频的真实结束事件。登录、验证码、网络故障或播放失败时保留网页提示，由用户处理或手动切歌。网站自动播放限制可能需要先在网页点一次播放；未开始播放不会被当作歌曲结束。
- B站歌单与本地 MP3 歌单分别保存，启动不自动打开网页。播放 B站视频会暂停 MP3，播放本地歌曲会停止网页；实际播放可带动唱歌和听歌计时，静音不发成长奖励。
- **网页声音使用 Windows 默认输出**，音乐页音量滑块可控制视频音量；应用内指定蓝牙耳机的设置只作用于本地 MP3。网页需用耳机时，请把 Windows 默认输出切到耳机。
- 需要联网及 Microsoft Edge WebView2 Runtime，首次运行脚本会补装 Python 网页依赖。登录与验证在网页内完成；网页登录缓存保存在 `%LOCALAPPDATA%\TianyiPet\WebPlayer`，独立于 Edge 浏览器。程序不解析或下载视频音频。

网页窗口使用 [pywebview 的 Windows Edge Chromium 后端](https://pywebview.flowrl.com/guide/web_engine.html)。B站页面结构和播放策略可能变化；若无法识别视频，使用“显示网页”查看提示并手动切歌。

## 运行

Python 3.10 或更高版本，双击“启动桌宠.bat”。首次运行自动安装项目虚拟环境中的 PySide6 与网页播放依赖，需要网络。手动启动：

依赖检查完成后，启动脚本使用窗口模式 Python，不留下控制台窗口。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app_entry.py
```

更新后从旧桌宠的系统托盘退出，再重新启动。程序只允许一个实例；托盘可找回角色、打开歌单或退出。

启动会先显示桌宠；本地音频设备改为首次播放 MP3 或打开音频设置时初始化。首次使用本地音乐仍可能等待设备就绪，B站播放不触发这部分初始化。素材透明边界扫描已加速，并复用裁切结果，保留原有的透明杂点过滤规则。

首次本地播放现在显示加载条，音频初始化和播放在独立进程完成，等待期间角色和界面继续响应。上下首及 B站标题回传会同时更新歌单窗口和角色旁的音乐菜单。

## Windows 安装包

最新安装包为 `TianyiPet-0.6.5-Setup.exe`，支持选择安装目录、创建快捷方式及卸载，无需安装 Python。首次使用工作模式会联网自动安装 Node.js 和官方后端。构建与使用说明见 [安装包说明](packaging/README.md)，更新内容见 [0.6.5 更新公告](docs/release-notes/0.6.5更新公告.txt)。先从托盘退出旧版再安装；本地用户设置、听歌记录和工作会话保留。

历史优化测试中，本机独立 Python 进程的离屏首帧测量从约 17.08 秒降至 1.66 秒，测试包含导入、窗口构造与首帧绘制，不含启动脚本和依赖安装。实际桌面启动时间会受磁盘、设备及缓存影响，可运行下方基准脚本自行测量。
