# 洛天依桌宠

Windows 本地音乐陪伴桌宠，正在按阶段开发。

## 当前版本：第一阶段原型

已实现透明置顶窗口、拖动与位置记忆、临时角色呼吸/眨眼/听歌摇摆、托盘菜单，以及 MP3 添加/拖入、播放暂停、上下首、进度与音量控制。导入列表和音量本地保存。

已接入 SQLite 听歌记录、每日音符奖励、投喂、饱食度、心情及等级逻辑，并在音乐面板显示数值。7 项逻辑测试及离屏界面初始化、投喂和渲染检查已通过。

已接入生成的透明 Q 版洛天依母版，支持整图轻微浮动与听歌摇摆。独立眨眼/投喂等逐帧动画、升级解锁、多歌单管理、播放位置恢复、鼠标穿透和安装包尚未实现。真实 MP3 解码、出声、原生桌面交互与长时间运行尚待实机验证。

角色现已改为经典 V3 公式服，提供圆润 Q 版与精致 Q 版两种画风，在“陪伴 → 天依的样子”或角色右键菜单切换；音乐面板采用卡片布局。服装参考与实际提示词见 `assets/character/V3公式服修正.md`，此前视觉记录保留在 `assets/character/视觉改版-v2.md`。如正在运行旧版，请从托盘退出再重新启动。

当前默认使用精致版，头顶八字辫已简化为平滑发束。此次更新首次启动会切换到精致版，之后仍可自行选择并记住外观。项目远程仓库：[Rhonsua/deskpet](https://github.com/Rhonsua/deskpet)。

## 运行

安装 Python 3.10 或更高版本后，双击 `启动桌宠.bat`。首次运行自动在项目虚拟环境中安装 PySide6，需要网络。也可手动执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

双击角色打开音乐面板，右键角色打开菜单。关闭音乐面板后音乐仍可播放；退出程序请使用角色或托盘菜单的“退出”。

MP3 保留在原位置，程序只保存路径。设置保存在当前 Windows 用户的 Qt 应用设置中。程序不附带音乐、不联网上传用户数据。

成长数据存放在 Qt 为应用分配的本地应用数据目录下的 `pet.db`。每秒采样并保存听歌记录；暂停、拖动进度条及超过 3 秒的采样间隔不计入听歌时长。应用内静音仍计时，但不发奖励。每累计 5 分钟有效听歌获得 5 经验和 2 音符，每日最多奖励 120 分钟。

## 逻辑测试

养成逻辑不依赖界面，可使用 Python 标准库执行测试：

```powershell
python -m unittest discover -s tests -v
```

测试覆盖奖励上限、静音、重启续算、跨午夜、投喂冷却和休眠间隔，7 项全部通过。界面检查可执行 `.\.venv\Scripts\python.exe tests/smoke_ui.py`，预览写入 `preview/`；测试数据库使用临时目录。
