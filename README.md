Windows 音乐桌宠，支持本地 MP3 与 B站网页歌单，默认使用经典 V3 公式服精致 Q 版。

## 和天依互动

启动后只显示角色。参考 [VPet 的角色工具栏与气泡交互](https://github.com/LorisYounger/VPet)，常用操作放在角色身边，歌单和设置按需打开。

| 操作 | 效果 |
| --- | --- |
| 点头部 | 摸头、闭眼挥手、爱心和本地对话气泡 |
| 点身体 | 戳一戳，惊讶回应 |
| 按住约 0.28 秒或拖动 | 提起，松开后落地回弹 |
| 拖到屏幕边缘后松手 | 自动吸附，稍后缩成探头；左右、上下边缘均支持 |
| 拖到边缘后继续往边缘推 | 不必松手，直接缩成探头吸附；按住往桌面拉回可立即解除 |
| 鼠标经过、单击或原地按住探头 | 保持吸附，不自动展开；按住并向桌面内拖动才拉出 |
| 右键或双击 | 展开/收起贴身菜单 |
| 菜单 → 投喂 | 使用音符兑换点心，播放抱包子动作 |
| 菜单 → 休息 → 盖被子睡觉 | 背对观众侧躺、盖被子、轻轻呼吸，点击唤醒 |
| 菜单 → 休息 → 熬夜玩手机 | 被窝看手机、手机微光和轻点反馈；点击收手机或选择起床 |
| 菜单 → 音乐 | 播放控制、歌单与添加 MP3 |
| 音乐 → 拿麦克风唱歌 / 收麦 | 持麦唱歌与左右侧转、点脚；也可切回陪伴听歌 |
| 音乐 → 拿麦克风转个身 | 临时完成一轮左右侧转，随后恢复原活动 |
| 菜单 → 设置 | 开机自启、角色大小与更多设置 |

待机有呼吸和眨眼；精致版唱歌时拿麦克风，循环正面与左右侧转姿态，腿部独立轻点、屈膝、改变重心，并浮出音符。目前为三方向素材结合程序形变，尚未实现逐帧行走、爬墙、360 度转身、完整舞蹈或骨骼动画；对话为本地预设文本。生成图与完整提示词见 [唱歌与侧转制作记录](assets/character/states/唱歌与侧转制作记录.md)。

[查看唱歌动作演示](docs/singing-demo.gif)。

已修复腿部运动的条带接缝漏底：腿部先连续采样合成，再随身体整体转动，避免运动时出现横向切割线。检查覆盖三个缩放比例、四个运动阶段和身体旋转，保留左右腿独立动作与对应点击区域。

## 持续状态与临时动作

待机、睡觉、玩手机、手动唱歌、收麦陪听是持续状态，会保存在设置中。提起、落地、摸头、戳一戳、投喂和转身是临时动作，结束后恢复持续状态。

- 睡觉或手机 → 提起 → 松手落地 → 继续睡觉或玩手机。
- 投喂 → 提起（投喂计时暂停）→ 落地 → 接着吃完 → 返回原活动；恢复动画不会再次扣音符或重复发奖励。
- 普通待机播放 MP3 时自动持麦唱歌；如果在拖动期间暂停播放，放下后按最新播放状态显示，不会恢复已经停止的唱歌。
- 明确点击起床、收手机或切换活动，会更新持续状态。拖拽只改变临时动作；拖动中明确选择的新活动也以最新选择为准。
- 重启恢复持续状态，临时动作不会写入设置。自动跟随的唱歌取决于真实播放状态，重启仍不自动播放音乐。

停靠使用当前屏幕的可用区域，底部避开任务栏。距离边缘约 32 个逻辑像素内松手会贴边，约 0.9 秒后缩回。也可不松手，继续向边缘推约 24 个逻辑像素，直接触发探头；同一次拖动中往回拉至桌面内约 12 个逻辑像素即可解除。距离随角色缩放调整，自动吸附后松手保持探头。互动、气泡、菜单或歌单打开时保持展开。睡觉和玩手机时也保持展开，显示完整枕头和被子，起床后恢复停靠。停靠边缘和位置会保存，缩放后仍贴边。透明画布每帧清空，避免动作切换留下旧像素；下拉框和菜单固定使用深色文字、浅色背景与深色选中项。

精致版新增的睡眠与手机状态素材使用内置 imagegen 生成。手机姿势参考本地用户素材，图与实际提示词见 [制作记录](assets/character/states/睡眠与手机制作记录.md)。动作由独立状态图结合程序呼吸、微光与点按反馈实现。圆润版缺少专属状态时回退到现有姿势。音乐可以在休息时继续播放，播放/暂停不会强制叫醒角色。

`characters/` 已提供自定义角色配置模板、动作回退约定与手动校验工具，见 [角色包说明](characters/README.md)。目前仅做接口准备，尚未开放外部角色加载或切换，也不会在启动时扫描角色包。

## 开机自启

在“右键天依 → 设置 → 开机自启”打开，或在更多设置中勾选“登录 Windows 后启动桌宠”。默认关闭。

自启只显示桌宠，不打开歌单，也不自动播放音乐，可随时取消。仅使用当前用户的 Windows 登录启动项，无需管理员权限；源码版通过项目虚拟环境的 pythonw.exe 和绝对路径启动，不显示控制台。移动项目或虚拟环境后，需重新开启一次自启。

## 鼠标穿透

在“右键天依 → 设置”或“更多设置”中勾选“鼠标穿透”，也可从 Windows 系统托盘的桌宠图标右键菜单切换。默认关闭，开启状态会保存。

开启后鼠标点击会穿过角色窗口，角色继续显示和播放动画。此时无法直接点击、拖动或右键角色；请右键系统托盘图标取消“鼠标穿透”，或选择“关闭鼠标穿透并找回天依”。歌单与设置窗口仍可操作，切换穿透不改变睡觉、唱歌等持续状态。

使用 [Qt 的 WindowTransparentForInput](https://doc.qt.io/qt-6.8/qt.html#WindowType-enum) 设置窗口输入穿透。离屏及 Windows 原生窗口检查覆盖开关同步、状态保存、重启恢复、托盘解除，以及原生穿透样式的设置与清除；不同桌面软件下的实际点击透传和长时间使用仍待确认。

## 音乐与成长

- 支持导入或拖入 MP3、文件夹当前层的 MP3。
- 支持创建、重命名、删除和切换歌单，搜索、移除和上下移动歌曲；磁盘文件保留。
- 支持顺序播放、列表循环、单曲循环、随机播放、进度拖动和音量。
- 保存上次歌曲、进度和播放方式，重启后点击播放继续；每 15 秒及关闭时保存。
- 旧单列表自动迁移；文件缺失会显示失效，播放时跳过缺失或解码失败的文件。
- 记录今日、本周、累计实际播放时长；暂停、跳进度和休眠间隔不虚增计时。
- 每 5 分钟有效播放获得 5 经验、2 音符，每日最多奖励 120 分钟；静音计时但不发奖。
- 投喂恢复饱食和心情；升级触发回应。摸头心情奖励每日最多 10 次、间隔至少 60 秒，动画互动不限次。

## 蓝牙耳机与音频输出

打开“右键天依 → 设置 → 更多设置 → 音频输出”。默认“跟随系统默认输出”，Windows 默认播放设备变化时自动更新；也可以直接选择已连接的蓝牙耳机或扬声器。设备列表会自动刷新，设置下方显示当前实际路由目标。

指定设备临时断开时会回退到当前默认输出，重新连接后恢复指定设备。切换时重新加载同一首歌并恢复进度，可能短暂停顿；原本暂停的歌曲保持不播放，歌单顺序和播放模式保留。程序不改变 Windows 的系统默认音频设置。

实现依据 [Qt QMediaDevices 设备变化通知](https://doc.qt.io/qtforpython-6.8/PySide6/QtMultimedia/QMediaDevices.html) 和 [QAudioOutput 输出设备接口](https://doc.qt.io/qtforpython-6.8/PySide6/QtMultimedia/QAudioOutput.html)。本机已识别 EDIFIER K710W，静音 MP3 的实际输出设备切换、暂停进度、恢复和单曲循环检查通过；未进行耳机实际听音确认。

## B站网页歌单

为了方便大家支持 P 主，添加了 bilibili 播放功能，欢迎通过原视频收听并支持喜欢的创作者。

右键天依 → 音乐 → B站网页歌单，或在音乐窗口点击“B站”。粘贴视频完整链接后点“添加链接”，双击歌单项开始播放。

- 只接受 `bilibili.com/video/BV…` 或 `…/video/av…` 的 HTTP/HTTPS 视频地址，支持 `?p=2` 指定分 P；会移除分享追踪参数。`b23.tv` 短链接请先在浏览器打开，复制展开后的完整地址。直播、番剧及其他网站不会加入歌单。
- 使用桌宠自己的 WebView2 播放窗口。暂停、继续、上一首、下一首及播放方式在 B站页控制；同一窗口切换歌曲，顺序播放到最后一首会关闭。点击“停止”或手动关闭网页也会停止，不会自动重开。
- 点击网页标题栏的最小化按钮，或歌单中的“最小化到托盘”，网页会收起到桌宠共用的系统托盘图标，音乐继续。右键托盘选择“显示 B站播放网页”可恢复；隐藏时自动切歌不会弹出网页。关闭按钮仍停止网页歌单。
- 单曲循环在同一页面从头重播，列表循环在最后一首结束后回到第一首；隐藏到托盘也遵循所选方式。修复网页原生循环吞掉结束事件，以及自动恢复播放覆盖结束标记的问题。
- 切歌依据网页视频的真实结束事件。登录、验证码、网络故障或播放失败时保留网页提示，由用户处理或手动切歌。网站自动播放限制可能需要先在网页点一次播放；未开始播放不会被当作歌曲结束。
- B站歌单与本地 MP3 歌单分别保存，启动不自动打开网页。播放 B站视频会暂停 MP3，播放本地歌曲会停止网页；实际播放可带动唱歌和听歌计时，静音不发成长奖励。
- **网页声音使用 Windows 默认输出**，音乐页音量滑块可控制视频音量；应用内指定蓝牙耳机的设置只作用于本地 MP3。网页需用耳机时，请把 Windows 默认输出切到耳机。
- 需要联网及 Microsoft Edge WebView2 Runtime，首次运行脚本会补装 Python 网页依赖。登录与验证在网页内完成；网页登录缓存保存在 `%LOCALAPPDATA%\TianyiPet\WebPlayer`，独立于 Edge 浏览器。程序不解析或下载视频音频。

网页窗口使用 [pywebview 的 Windows Edge Chromium 后端](https://pywebview.flowrl.com/guide/web_engine.html)。B站页面结构和播放策略可能变化；若无法识别视频，使用“显示网页”查看提示并手动切歌。

## 运行

Python 3.10 或更高版本，双击“启动桌宠.bat”。首次运行自动安装项目虚拟环境中的 PySide6 与网页播放依赖，需要网络。手动启动：

依赖检查完成后，启动脚本使用窗口模式 Python，不留下控制台窗口。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

更新后从旧桌宠的系统托盘退出，再重新启动。程序只允许一个实例；托盘可找回角色、打开歌单或退出。

启动会先显示桌宠；本地音频设备改为首次播放 MP3 或打开音频设置时初始化。首次使用本地音乐仍可能等待设备就绪，B站播放不触发这部分初始化。素材透明边界扫描已加速，并复用裁切结果，保留原有的透明杂点过滤规则。

首次本地播放现在显示加载条，音频初始化和播放在独立进程完成，等待期间角色和界面继续响应。上下首及 B站标题回传会同时更新歌单窗口和角色旁的音乐菜单。

## Windows 安装包

已提供本地生成的 0.2.0 试用安装包和免安装 ZIP，构建与使用说明见 [安装包说明](packaging/README.md)。安装版无需安装 Python，支持选择安装位置、快捷方式及卸载；用户设置与听歌记录保留。退出旧版桌宠后再安装或启动新版。

本机独立 Python 进程的离屏首帧测量从约 17.08 秒降至 1.66 秒，测试包含导入、窗口构造与首帧绘制，不含启动脚本和依赖安装。实际桌面启动时间会受磁盘、设备及缓存影响，可运行下方基准脚本自行测量。

逻辑测试共 57 项，56 项通过，1 项符号链接校验因本机不支持创建链接而跳过。离屏交互检查、本地生成静音 MP3 的解码、计时、跳转、暂停恢复和单曲循环检查已通过。停靠检查在离屏及 Windows 窗口后端均通过，覆盖四边探头、按住推入吸附与反向拉回、展开/缩回、缩放、恢复、拖出停靠、连续绘制清屏，以及深色系统配色下的下拉选项。新增音频检查覆盖默认设备切换、指定设备、断线回退与重连策略、真实输出切换中的歌曲和进度保留。新姿势检查覆盖横向睡眠、手机与睡眠互斥、点击起床以及音乐不强制唤醒。自启测试使用独立测试注册表位置；实际注销/登录、桌面长时间显示与点击穿透、真实多屏拖拽、蓝牙设备实际断线重连与耳机听感尚待验证。
