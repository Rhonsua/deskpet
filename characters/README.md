# 自定义角色（预留）

这里预留给其他人放置自己的角色包。当前版本仍从 `assets/character/` 加载内置洛天依，**尚未读取本目录，也没有导入或切换外部角色的入口**。

后续计划每个角色独立一个文件夹，例如：

```text
characters/
  my-character/
    character.json
    idle.png
    blink.png
    happy.png
    eat.png
    lift.png
```

约定草案：PNG 使用真正透明背景，各状态保持一致的画布尺寸、角色比例与脚底位置；提供默认站立图，其余状态可选，缺少时回退到默认图。角色配置将包含显示名称、作者、素材来源、状态文件及头部/脚底锚点，让探头与拖拽适配不同角色。

接入顺序：确定配置格式 → 限制素材路径在角色目录内 → 校验图片和回退 → 设置中扫描/切换 → 测试不同体型的点击区域与边缘探头。格式完成前，不建议发布依赖此草案的角色包。
