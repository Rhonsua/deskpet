洛天依桌宠 0.7.0 · 本机语音环境安装助手

群友需要桌宠 0.7.0、这个辅助包，以及群里单独提供的 A 或 C 语音包。

1. 完整解压本辅助包，双击 TianyiVoiceSetup.exe。A-演出原声.zip 或 C-演唱微调.zip 保持 ZIP 格式，可放在 EXE 旁边或稍后点「选择」。
2. 选一个有约 25 GiB 空闲空间的磁盘目录，例如 D:\桌宠语音。点「开始安装」。首次会下载约 8.84 GB 的官方公共环境，包含专用 Python、推理引擎及公共底模。下载可以暂停，下次选同一目录可续传；安装成功后自动移除助手下载的 7z。
3. 如果选择了 A 或 C，助手会实际合成一句话做自检，再把语音包和环境路径接到当前 Windows 用户的桌宠。只安装环境也可以，之后点「打开语音包文件夹」放入 ZIP。
4. 从托盘退出并重新打开桌宠，在「和我聊天 → 陪伴模式 → 语音设置」选择声音，点「试听」。想朗读聊天回复，再打开「朗读回复」。

网络较慢时，如果已经拿到同版官方文件 GPT-SoVITS-v2pro-20250604-nvidia50.7z，可在「已有官方环境」中选择。助手核验 SHA-256 后直接解压。可从作者仓库获取这个文件：
https://huggingface.co/lj1995/GPT-SoVITS-windows-package/blob/c8b61d4f627d1f02e74c1ba158a4844051d2289f/GPT-SoVITS-v2pro-20250604-nvidia50.7z

目标系统为 Windows 10/11 x64。采用带 CUDA 的运行环境，可用的 NVIDIA 显卡优先，否则由 CPU 推理；CPU 首句可能比较慢。无需另装 Python、CUDA Toolkit 或启动网页服务。
环境位置为所选目录下的 TianyiVoice-v2Pro-20250604。桌宠升级后可以继续用。切换音色时直接在桌宠中选择语音包即可。

安装失败时，先读弹窗中的具体原因。模型加载和解压诊断位于 %LOCALAPPDATA%\TianyiPet\TianyiPet\voice-setup\install.log。联网使用固定版本和 SHA-256 校验；助手在本机处理语音包，不上传模型、群聊或录音。

公共环境来自 GPT-SoVITS 作者发布的 Windows 整合包：
https://github.com/RVC-Boss/GPT-SoVITS
