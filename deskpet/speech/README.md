# 本机洛天依语音

## 平时怎么用

1. 从桌宠打开“和我聊天”，进入“陪伴模式”。
2. 点底部“开启并试听”。桌宠会记住“朗读回复”的选择，准备好声音后播放“你好呀，我是洛天依。”。试听使用本机模型。
3. 下次启动桌宠时，已开启的语音会自动预热。声音模型和音频设备在各自的后台进程中并行准备。你可以在准备期间拖动桌宠、打字聊天，打开聊天窗口即可看到当前状态。
4. 发送聊天消息。开启朗读时，天依先写好回复并合成声音，准备好后一起显示文字、播放语音。声音准备失败时仍会显示文字。关闭朗读后按原来的文字聊天方式显示。

“停读”可取消当前合成和播放。“停止”可同时取消当前文字请求。发送新消息会取消旧语音。关闭聊天窗口会取消当前朗读，后台可以继续准备或保留已加载的声音。取消勾选“朗读回复”或退出桌宠会释放模型。语音默认关闭。

开启“空闲时由 AI 主动聊天”和“朗读回复”后，天依主动搭话时也会把气泡和声音一起送出。准备期间如果你开始互动，这次主动搭话会让位。朗读使用内置洛天依的声音，仅用于陪伴模式，输出设备跟随音乐设置。

在“语音设置”中拖动音量滑块，点“保存”应用，或直接点“试听”应用并听效果。0% 为静音。缺少运行文件时，会自动展开高级设置并标明缺少哪一项。

## 添加语音包

在「和我聊天 → 陪伴模式 → 语音设置」点「打开文件夹」，把 ZIP 原样放进去。列表会自动刷新，也可以点「刷新」。选择语音包后点「试听」或「保存」，下次沿用这次选择。首次使用时后台会展开并缓存模型。Windows 默认目录为 `%LOCALAPPDATA%\TianyiPet\TianyiPet\语音包`。语音包使用本机配置的 GPT-SoVITS 环境及与版本匹配的公共底模。

制作中文声音包时，把以下 `voice.json` 和它引用的文件放入 ZIP。路径相对于清单所在目录。参考录音使用 3～10 秒的 PCM WAV，`text` 填写录音中实际说的台词。

```json
{
  "format": 1,
  "version": "v2Pro",
  "gpt": "weights/gpt.ckpt",
  "sovits": "weights/sovits.pth",
  "reference": "ref.wav",
  "text": "刚刚演唱的这些歌曲，大家都喜欢吗？"
}
```

已有的 ZIP 如果只有一份 `.ckpt`、一份带版本标记的 `.pth`、一段 WAV，以及同名 `.txt` 或 `prompt.txt`，也可以直接导入。多份参考录音或没有版本标记的权重使用 `voice.json` 指定。

## 配置与迁移

默认读取项目下 `local-work/tianyi-tts/speech-config.json`，从其中的 `python` 和 `engine_root` 发现独立运行环境；没有这两个字段时，使用同目录的 `runtime/Scripts/python.exe` 和 `GPT-SoVITS`。高级设置中已保存的非空路径优先。配置文件内这两个字段也可使用相对于配置文件的路径。模型和参考音频路径使用绝对路径。

```json
{
  "python": "独立 Python 可执行文件路径",
  "engine_root": "GPT-SoVITS 根目录",
  "model": {
    "device": "cuda",
    "is_half": true,
    "version": "v4",
    "t2s_weights_path": "GPT 权重路径",
    "vits_weights_path": "SoVITS 权重路径",
    "bert_base_path": "中文 BERT 目录",
    "cnhuhbert_base_path": "中文 HuBERT 目录"
  },
  "reference": {
    "audio": "参考音频路径",
    "text": "参考音频准确文字",
    "language": "zh"
  },
  "inference": {
    "sample_steps": 16,
    "speed_factor": 1.0
  }
}
```

语速由配置中的 `inference.speed_factor` 控制，默认 1.0，允许 0.5–2.0。修改声音配置文件后，请关闭再开启语音回复，以重新加载；此操作也适用于更换模型。CPU 使用 `device: cpu`、`is_half: false`，速度取决于本机性能。

0.7.0 桌宠的本机语音需另备模型、运行环境和参考音频。后台强制安全权重加载，初始化失败不会退回不安全模式；合成超时或用户停止会取消本次工作。若没有声音，先查看语音状态，再检查语音音量、音乐输出设备和系统音量。
