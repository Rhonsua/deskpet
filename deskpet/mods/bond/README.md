# 互动养成增强包 0.2.3

这是可运行的独立 Mod，需要 **0.7.2 或更新版本主程序的 Mod API 3**。请先更新主程序，再安装本扩展；本包不能代替主程序更新。本体和 Mod 分开分发，不包含个人音乐、聊天数据或语音模型。纪念册插图来源及权利说明见 [素材说明](assets/SOURCES.md)。

0.2.3 重排演出与设置页面，按系统适配深浅主题，采用洛天依青蓝音乐主题、清晰卡片与紧凑操作；高级参数默认折叠。纪念册进入页面才加载，记录不变时不重复分页，收藏谱仅在变化时重新解析。隐藏窗口停止界面刷新；关闭猜歌、演出选曲窗口时无需等待后台扫描结束。

窗口使用真正铺满的天依插画背景，文字放在半透明卡片上，不再使用人物侧栏冒充背景。顶部「调整背景」可以拖动图片、调整缩放，保存为养成窗口独立的背景位置；不会改变聊天或歌单背景。原图不被修改，包内仅使用约 151 KiB 的缩小副本；未提供插图时回退为纯色主题。

## 书本式成长纪念集

从主面板的「成长纪念集」进入。天依插画扉页、暖白纸张、书脊与页边，六枚书签分别查看封面、六阶段成长、互动图鉴、听歌纪念、日常留笺和本周回忆。宽窗口双页，窄窗口单页；可以点击翻页按钮、页角，或使用左右方向键。长记录自动续页，新增记录保留正在阅读的那一页。未发生的经历不填充虚构内容，未抵达的阶段标记待续。本周回忆仍在「信赖」阶段开放。

纪念册是透明无边框的独立书窗，整个界面只显示书本，没有外围底色、标题栏或成长面板。章节书签贴在书本上缘；返回、关闭、页码、翻页和导出在书内操作。按住书页可拖动窗口，点击「返回」回到今日陪伴。窄窗口书签分成两排，不挤压正文；猜歌和三曲演出继续由主面板入口进入。返回后，其余页面继续显示原有天依背景。

立绘已压缩为约 86 KiB 的透明 WebP，本地读取，打开纪念集不会联网。素材缺失时用花形封面替代，不影响养成或历史记录。

0.2.2 进一步区分互动贴纸、听歌唱片和演出票根，按真实记录类型绘制；显示首次日期、章节收录数量、最近收录和六阶段进程。新增装饰均由 Qt 绘制，不增加外部图包。

「今天的陪伴」使用五类互动卡片，状态与入口放在一起，顶部只推荐一件小事，完成后显示轻松结束提示。新版宿主的通用入口可直接打开原控制面板、投喂、陪伴聊天或歌单；打开页面本身不计成长，摸头仍需从原控制面板手动进入。较早的 API 3 宿主没有入口能力时会提示使用原面板。昵称和舞台选项放在「舞台与纪念」，窄窗口中可滚动查看。

## 安装与入口

1. 使用支持 API 3 的主程序，打开「扩展功能 / Mod → 打开 Mod 文件夹」。
2. 解压 ZIP，使 `bond/mod.json` 和 `bond/entry.py` 直接位于 Mod 目录下，不再套一层压缩包名称目录。
3. 重启桌宠，启用「互动养成增强包」。主面板出现今日进度、节奏演出、纪念册、更多互动。以后无需进入 Mod 管理页才能玩。

「更多互动」可以调整固定的两个入口，或隐藏摘要；其余功能仍在菜单中。扩展管理页只需用于启停和调整各 Mod 共用的通知频率。

成长纪念集以独立的透明无边框书窗打开，整个界面只呈现书本；按住书页可拖动位置。书内「返回」恢复养成首页，「关闭」收起书窗，翻页、分类和导出也都在书上。

## 成长与一天的陪伴

亲密度是本包唯一主成长线，阶段等级由它推导。原经验冻结，不被覆盖；音符、饱食和心情保留。停用后恢复原来的等级和经验，纪念册与亲密度保留。

| 每日类别 | 可完成方式 |
| --- | --- |
| 摸头 | 原控制面板进入摸头，完成真实互动 |
| 照料 | 成功投喂；饱食达到 95 时也可选择「已经吃饱，让她歇歇」 |
| 说话 | 陪伴聊天成功交付回复；没配 API 时可用「说说今天」留下离线留言 |
| 共处 | 正常可听播放累计 10 分钟，或主动开启 10 分钟安静陪伴并到点确认 |
| 游戏 | 完成节奏演出并击中至少 min(5, 谱面音符数) 个音符，或完成三题猜歌 |

每类每天首次 +10，每日共 50。同类重复仍有反馈，不刷亲密度；缺席不扣，时钟倒退不重开旧奖励日。不用困难谱、连击或正确率卡成长。前四类和一局小游戏可以在约 10～15 分钟内完成；具体取决于个人操作，不是已完成一周用户体验验证。

六阶段：初识 0、熟悉 40、信赖 150、默契 350、知心 700、陪伴 1400。第一天能到熟悉，完整完成每日互动约 28 天到陪伴。已有桌宠功能不会重新锁住。阶段开放称呼、配色舞台、本周回忆及纪念；用户打开的养成页会显示阶段卡，并在桌宠可用时播放挥手、转身、庆祝。忙碌时保留纪念供稍后查看。

## 下落式节奏演出

- 三轨 D/F/J、四轨 D/F/J/K，可在开局前调整按键；鼠标模式使用独立的单手谱。
- 单点、长条、双押。长条按中头部后保持到尾部，无需刻意踩点松开；鼠标按住后锁定最初轨道，不因小幅横移换轨。
- 入门、标准、进阶；30/45/60 秒片段，可自动选取拍点较集中的区域，也可指定开始位置。选择文件至少 35 秒，实际片段会按歌曲长度缩短。
- **花样演出**每次准备新谱时生成新编排；**标准挑战**在相同音频、分析、片段、难度和输入方式下可复现。局内不变谱；「原谱再来一次」始终保留该谱。
- 使用真实拍点、起音和稳定能量区间，按短乐句选择交替、重复、内外移动等手序，并检查同轨重叠、长条占轨和最大双押。鼠标谱不会要求双押或在长条期间点另一轨。
- 首次分析放在独立进程，可取消，同一养成包同时只分析一个文件；后续复用缓存，不因换种子重新解码。音频身份使用本地路径、大小、修改时间。自动分析是估计，持续能量不等同于识别人声延音，也不保证自动选到副歌。
- 低置信片段或分析失败时明确询问是否使用 BPM 练习谱；没音乐也能做标明为练习的离线演出。
- 完美 ±85 ms、良好 ±180 ms。按音频位置判定，显示帧率不改变谱面时刻。每谱满分 1,000,000；长条总权重与单点相同，不能靠拖长长条刷成长。
- 可调下落可见提前量和输入偏移。暂停或失焦会暂停声音并清除按键；继续前倒计时两秒，跨暂停长条请重新按住对应按键。
- 命中有可关的粒子和判定音，连击提升舞台效果并请求桌宠动作；失误不停止歌曲，也不批评玩家。结算保存同谱最高分、连击、判定数；收藏保存完整谱面，原文件改变时要求重新准备。

普通歌单正在播放时，需先主动暂停。恢复普通播放会结束当前互动音频；小游戏不抢回播放器、不改原歌单。音量和输出设备遵循桌宠设置，蓝牙延迟可通过输入偏移自行校准。

## 猜歌、小心愿与隐藏发现

猜歌从已有本地歌单或主动补充的文件读取元数据，需要至少三首歌名不同且可播放的曲目。每局三题，每题听八秒、三选一；不调用 AI 猜答案。试听、作答与反馈分开显示，作答前可以重听同一片段，不换题、不重复计分。音频必须播放成功才能作答。答错展示正确歌名，有同名 LRC 时附真实歌词提示；全对额外留下本轮歌名纪念。

熟悉后，空闲时可能出现小心愿：摸头、照料、听歌、视线回应或安静陪伴。普通心愿提供两分钟回应时间，安静需求保留十五秒不互动，不显示秒级催促。当天不重复相同种类；吃饱或没有本地歌单时不会抽到对应需要。默认每日最多三次，可调为 0～5；仍受全部 Mod 共用的免打扰、总次数和冷却约束，实际次数可能更少。失败/过期不扣数值；安静需求只看桌宠互动，不监控其他软件。

心愿出现时可选「稍后」（至少暂停 30 分钟）或「今天先安静」（当天不再提小心愿）；选择本地保存，重启有效，不影响主动聊天、其他 Mod 通知或升级纪念。关闭心愿不会发奖励、补问或扣亲密度。工作、拖拽等忙碌期间，阶段提示也会延后。

真实的互动组合会留下首次发现记录，包括连续的温柔互动、动作之间的小衔接和梦里音乐等。主面板不列完整触发公式。

## 回忆、唱片与舞台

- 动作真实触发后收录首日；相遇、阶段、生日、固定节日和相遇周年写入纪念册。生日需自己填写，留空不记录。
- 本周回忆由真实互动天数、听歌时长、主动留言及完成演出组成。用户保存喜爱歌曲或明确记录疲惫后，可在之后触发有冷却的关心；不推断未发生的聊天，也不自动打断音乐。
- 本地歌曲自然结束、实际可听覆盖达到 90% 且听到末尾附近时，累计完整播放次数，1/3/10 次收录唱片纪念。跳播、片段、静音与重启不拼成完整一首。网页和云端当前只记录已验证的时长，不冒认完整播完。
- 三曲小演出由用户选三首不同本地歌曲，各播 30 秒，总计 90 秒；演出时收起选歌区，展示节目单、三幕标题与进度。持麦天依在三个已有姿态之间过渡，每幕随真实播放进度淡入登场、淡出退场，可暂停并选择谢幕动作；暂停、隐藏或最小化时停止舞台动画计时。它是插画姿态演出，尚无逐曲专属编舞或歌词口型。完整完成才保存节目单和每周纪念，失败不记为完成；结束后可直接打开纪念册，导出最近节目单、阶段或本周回忆 PNG。
- 海底回响、花间小调、星光剧院分别售价 60/100/150 音符：海浪/气泡/光束、花枝/落樱、帷幕/聚光/星光。设置页可免费预览，点击「获得并使用」才购买；装饰用于节奏演出和三曲小演出，已拥有后可反复使用。扣款与拥有记录在宿主数据库同一事务中完成，重复点击不重复收费。没有抽卡。节奏演出关闭光效时保留静态场景，不遮挡音符与判定线。

新服装、双人立绘、特殊录音和专属编舞需要对应素材，本包没有伪装成已完成的购买或解锁入口。现有模型不支持某个展示动作时直接跳过；拖拽、摸头、睡眠和工作任务优先。

## 存档、缓存与退出

Mod 数据位于用户数据目录 `mods/bond/bond.db`；升级旧结构前保存一份 `bond.previous.db`。装饰购买凭据位于原 `pet.db` 的独立表，不改写旧 XP。未收藏谱面最多保留最近 100 份，分析缓存最多 100 个文件、100 MiB；永久收藏与用户 MP3/LRC 不会因此被删。

偏好和疲惫记录可从「舞台与纪念 → 查看 / 删除偏好与近期记录」删除。仅在照常使用陪伴 API 时，少量事实加入上下文；没有后台额外 AI 调用，不改变工作模式人设。停用保留数据，停止注入、计时、入口、分析和音频。

构建：`.venv\Scripts\python.exe packaging/build_bond_mod.py`，输出 `dist/TianyiPet-BondCompanion-0.2.3.zip` 及 SHA-256 文件。包中包含代码、说明、代码许可证，以及本机存在时的主题插图；不包含用户存档或音乐。插图独立权利说明见 `assets/SOURCES.md`。

相关回归测试：`test_bond_mod`、`test_bond_rhythm`、`test_bond_activities`、`test_bond_listening`，以及书册、首页和心愿检查 `test_bond_album`、`test_bond_dashboard`、`test_bond_events`。`smoke_bond_mod.py` 在隔离存档中验证真实桌宠与独立包；`smoke_bond_audio.py` 仅用一首小型合成 MP3 静音检查分析、缓存、暂停、重复播放和无标签元数据。未进行整歌单压测、真实七天体验或多设备蓝牙手感验证。
